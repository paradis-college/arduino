### E Ca și Cum Ți-ai Închide Ochii! 🙈

```cpp
digitalWrite(13, HIGH);  // Lumină APRINSĂ
delay(2000);             // Închide ochii pentru 2 secunde...
                         // Nu poate vedea nimic!
                         // Nu poate face nimic!
digitalWrite(13, LOW);   // Lumină STINSĂ (în sfârșit!)
```

<InfoBox type="warning">
  **În timpul delay(2000):** Arduino doarme complet! Chiar dacă apeși un buton de 100 de ori, Arduino nu va observa! 😴
</InfoBox>

### Problema cu Butonul 🔘

Imaginează-ți asta: Vrei ca o lumină să clipească ȘI să răspundă la un buton.

```cpp
void loop() {
  // Verifică butonul
  if (digitalRead(2) == LOW) {
    // Fă ceva când e apăsat!
  }

  // Clipește lumina
  digitalWrite(13, HIGH);
  delay(2000);  // Doarme 2 secunde - RATEAZĂ BUTONUL!
  digitalWrite(13, LOW);
  delay(2000);  // Doarme din nou - RATEAZĂ BUTONUL!
}
```

<LessonChapter title="Când Delay E OK! ✅" id="cand-delay-e-ok">

Delay E bine pentru lucruri simple:

### ✅ OK: Clipire simplă de lumină

```cpp
void loop() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}
```
Asta e bine dacă nu ai nevoie de butoane sau senzori!

### ✅ OK: Delay-uri scurte

```cpp
delay(10);  // Doar 10 milisecunde - super rapid!
```
Delay-urile scurte sunt de obicei OK pentru că Arduino se trezește rapid!

### ✅ OK: Mesaj de pornire

```cpp
void setup() {
  Serial.begin(9600);
  Serial.println("Pornesc...");
  delay(2000);  // OK aici - doar o dată la început
}
```

Există o cale MAI BUNĂ! În loc să doarmă, Arduino poate SĂ SE UITE LA UN CEAS! ⏰

### Ideea (Nu-ți Fă Griji de Cod Încă!)

- **delay()** = Închide ochii și numără 🙈
- **millis()** = Tot te uiți la un ceas ⏰👀

Cu metoda ceasului, Arduino rămâne treaz și poate face MULTE lucruri!

<InfoBox type="info">
  **Vei învăța millis() mai târziu!** Deocamdată, doar ține minte: există o cale să temporizezi lucruri FĂRĂ să dormi! 🎉
</InfoBox>

<LessonChapter title="Ai Reușit! 🏆" id="rezumat">

### Ce ai învățat azi:

- ✅ **delay()** face Arduino să DOARMĂ și să nu facă nimic altceva
- ✅ În timpul delay, Arduino poate **rata apăsări de buton**
- ✅ **Delay-urile scurte** sunt de obicei OK
- ✅ **Delay-urile lungi** pot fi o problemă dacă trebuie să răspunzi la lucruri
- ✅ Există o cale mai bună numită **millis()** (vei învăța mai târziu!)

# LED Blink de bază

În această lecție vei învăța cum să aprinzi și să stingi un LED folosind Arduino. Este primul pas în lumea electronicii și programării cu microcontrolere!

## Ce vei învăța

- Cum funcționează un LED
- Cum să folosești funcția `pinMode()`
- Cum să folosești funcția `digitalWrite()`
- Cum să folosești funcția `delay()`

<InfoBox type="info">
  LED-ul (Light Emitting Diode) este o componentă electronică care emite lumină când curentul electric trece prin ea.
</InfoBox>

## Componentele necesare

Pentru acest proiect ai nevoie de:

- 1x Arduino Uno
- 1x LED (orice culoare)
- 1x Rezistor 220Ω
- Fire de conexiune
- Breadboard

## Schema de conectare

Conectează LED-ul la pinul 13 al Arduino:

1. Conectează piciorul lung (anodul +) al LED-ului la pinul 13
2. Conectează piciorul scurt (catodul -) la rezistor
3. Conectează celălalt capăt al rezistorului la GND

<InfoBox type="warning">
  Întotdeauna folosește un rezistor cu LED-ul! Fără rezistor, LED-ul poate arde.
</InfoBox>

## Codul

```cpp
// Definim pinul pentru LED
const int LED_PIN = 13;

void setup() {
  // Setăm pinul ca ieșire (OUTPUT)
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Aprindem LED-ul
  digitalWrite(LED_PIN, HIGH);
  
  // Așteptăm 1 secundă (1000 milisecunde)
  delay(1000);
  
  // Stingem LED-ul
  digitalWrite(LED_PIN, LOW);
  
  // Așteptăm încă 1 secundă
  delay(1000);
}
```

## Explicația codului

### `pinMode(pin, mode)`

Această funcție configurează un pin ca intrare (INPUT) sau ieșire (OUTPUT).

- `pin` - numărul pinului
- `mode` - `INPUT` sau `OUTPUT`

<Checkpoint id="checkpoint-1" lessonKey="ro/basics-blink" label="Am înțeles funcția pinMode()" />

### `digitalWrite(pin, value)`

Scrie o valoare digitală (HIGH sau LOW) pe un pin.

- `HIGH` = 5V (LED aprins)
- `LOW` = 0V (LED stins)

### `delay(ms)`

Oprește execuția programului pentru un număr specificat de milisecunde.

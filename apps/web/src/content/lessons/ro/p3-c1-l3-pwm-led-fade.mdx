# PWM - Estompare LED (analogWrite)

În această lecție, vei învăța cum PWM (Pulse Width Modulation - Modularea Lățimii Pulsului) îți permite să controlezi luminozitatea LED-ului în mod gradual, nu doar ON sau OFF! 🌟✨

<LessonChapter title="Ce Vei Învăța" id="ce-vei-invata">

- Ce este PWM și cum funcționează
- Cum folosești `analogWrite()` pentru valori de la 0 la 255
- Cum creezi efecte de estompare (fade in/out)
- Care pini de pe Arduino suportă PWM

<InfoBox type="info">
  PWM creează iluzia unui semnal analog folosind comutări digitale foarte rapide. Ochiul tău vede luminozitatea medie! Este ca și cum ai clipi foarte repede - în funcție de cât timp ții ochii deschiși, vezi mai multă sau mai puțină lumină! 👁️✨
</InfoBox>

<LessonChapter title="Ce Este PWM?" id="ce-este-pwm">

### Modularea Lățimii Pulsului - Explicație Simplă

PWM comută rapid între HIGH și LOW:
- **Ciclul de lucru** (Duty Cycle): Procentul de timp în care semnalul este HIGH
- 0% = întotdeauna LOW (LED oprit ⚫)
- 50% = jumătate HIGH, jumătate LOW (luminozitate medie 🔆)
- 100% = întotdeauna HIGH (luminozitate maximă 💡)

<InfoBox type="tip">
  **Pentru copii:** Imaginează-ți că ai o lanternă și o aprinzi și o stingi FOARTE repede. Dacă o ții aprinsă mai mult timp decât stinsă, pare mai strălucitoare! Dacă o ții stinsă mai mult, pare mai slabă. PWM face exact acest lucru, dar de mii de ori pe secundă! 🔦⚡
</InfoBox>

### Cum Funcționează?

```
100% (HIGH tot timpul):   ████████████████████
 75% (3/4 HIGH):          ████████████████░░░░
 50% (jumătate HIGH):     ████████████░░░░░░░░
 25% (1/4 HIGH):          ██████░░░░░░░░░░░░░░
  0% (LOW tot timpul):    ░░░░░░░░░░░░░░░░░░░░

█ = HIGH (5V)   ░ = LOW (0V)
```

### Pinii PWM pe Arduino Uno

Doar anumiți pini suportă PWM (sunt marcați cu ~):
- **Pinii 3, 5, 6, 9, 10, 11**

Caută simbolul **~** (tildă) lângă numărul pinului pe placa Arduino!

<InfoBox type="warning">
  Pinul 13 NU suportă PWM! Dacă vrei să controlezi luminozitatea, folosește pinii 3, 5, 6, 9, 10 sau 11 pentru analogWrite().
</InfoBox>

<LessonChapter title="Funcția analogWrite()" id="functia-analogwrite">

### Sintaxa

```cpp
analogWrite(pin, valoare);
```

- `pin`: Un pin capabil de PWM (marcat cu ~)
- `valoare`: De la 0 la 255
  - **0** = 0% ciclu de lucru (oprit complet)
  - **127** = ~50% ciclu de lucru (luminozitate medie)
  - **255** = 100% ciclu de lucru (luminozitate maximă)

### Tabel de Referință Valori

| Valoare | Ciclu de Lucru | Luminozitate |
|---------|----------------|--------------|
| 0 | 0% | Oprit ⚫ |
| 64 | 25% | Slab 🌑 |
| 127 | 50% | Mediu 🔆 |
| 191 | 75% | Strălucitor 💡 |
| 255 | 100% | Maxim ☀️ |

### Exemplu

```cpp
const int PIN_LED = 9;  // Trebuie să fie un pin PWM

void setup() {
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  analogWrite(PIN_LED, 64);   // 25% luminozitate - ca o lumină de noapte
  delay(1000);
  analogWrite(PIN_LED, 127);  // 50% luminozitate - mediu
  delay(1000);
  analogWrite(PIN_LED, 255);  // 100% luminozitate - strălucitor!
  delay(1000);
}
```

<InfoBox type="tip">
  **Pentru copii:** Gândește-te la valorile 0-255 ca la un dimmer (reglaj de lumină) ca acela pe care îl au unii oameni acasă. Poți roti butonul pentru a face lumina mai slabă sau mai puternică! 🎛️
</InfoBox>

<LessonChapter title="Efecte de Estompare" id="efecte-estompare">

### Fade In și Fade Out - Lumina Care "Respiră"

Acest cod face LED-ul să crească și să scadă în luminozitate, ca și cum ar respira:

```cpp
const int PIN_LED = 9;

void setup() {
  pinMode(PIN_LED, OUTPUT);
}

void loop() {
  // Fade In - luminozitatea crește treptat
  for (int luminozitate = 0; luminozitate <= 255; luminozitate += 5) {
    analogWrite(PIN_LED, luminozitate);
    delay(30);  // Mică pauză între schimbări
  }
  
  // Fade Out - luminozitatea scade treptat
  for (int luminozitate = 255; luminozitate >= 0; luminozitate -= 5) {
    analogWrite(PIN_LED, luminozitate);
    delay(30);  // Mică pauză între schimbări
  }
}
```

<InfoBox type="info">
  **Cum funcționează:** Bucla `for` crește valoarea `luminozitate` de la 0 la 255 în pași de 5. La fiecare pas, actualizează LED-ul cu noua valoare. Pauzele de 30ms fac tranziția vizibilă și lină!
</InfoBox>

### Ajustarea Vitezei

- **delay() mai mic** = estompare mai rapidă
- **pas mai mare** (ex: `+= 10`) = tranziție mai puțin lină, dar mai rapidă
- **pas mai mic** (ex: `+= 1`) = tranziție foarte lină, dar mai lentă

### Exemple de Variații

```cpp
// Estompare RAPIDĂ
for (int b = 0; b <= 255; b += 10) {
  analogWrite(PIN_LED, b);
  delay(10);  // Pauze foarte scurte
}

// Estompare LENTĂ și LINĂ
for (int b = 0; b <= 255; b += 1) {
  analogWrite(PIN_LED, b);
  delay(50);  // Pauze mai lungi
}
```

<InfoBox type="tip">
  **Pentru copii:** Este ca și cum ai umple o cană cu apă - poți turna mult și repede, sau puțin câte puțin. LED-ul "se umple" cu lumină în același fel! 🥛💡
</InfoBox>

</LessonChapter>

<LessonChapter title="LED RGB - Amestecă Culori!" id="led-rgb">

### Creează Orice Culoare!

Un LED RGB conține de fapt 3 LED-uri în unul: Roșu, Verde și Albastru. Controlând luminozitatea fiecăruia cu PWM, poți crea milioane de culori!

```cpp
const int PIN_ROSU = 9;
const int PIN_VERDE = 10;
const int PIN_ALBASTRU = 11;

void setup() {
  pinMode(PIN_ROSU, OUTPUT);
  pinMode(PIN_VERDE, OUTPUT);
  pinMode(PIN_ALBASTRU, OUTPUT);
}

void setareCuloare(int r, int g, int b) {
  analogWrite(PIN_ROSU, r);
  analogWrite(PIN_VERDE, g);
  analogWrite(PIN_ALBASTRU, b);
}

void loop() {
  setareCuloare(255, 0, 0);     // Roșu pur 🔴
  delay(1000);
  setareCuloare(0, 255, 0);     // Verde pur 🟢
  delay(1000);
  setareCuloare(0, 0, 255);     // Albastru pur 🔵
  delay(1000);
  setareCuloare(255, 255, 0);   // Galben (Roșu + Verde) 🟡
  delay(1000);
  setareCuloare(255, 0, 255);   // Magenta (Roșu + Albastru) 🟣
  delay(1000);
  setareCuloare(0, 255, 255);   // Cyan (Verde + Albastru) 🩵
  delay(1000);
  setareCuloare(255, 255, 255); // Alb (toate culorile) ⚪
  delay(1000);
}
```

<InfoBox type="info">
  **Pentru copii:** Este ca atunci când amesteci vopsele! Roșu + Galben = Portocaliu. Cu LED-uri RGB, poți face același lucru cu lumină! 🎨
</InfoBox>

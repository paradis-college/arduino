### Mai întâi, spune-i Arduino-ului despre toți cei 3 pini

```cpp
void setup() {
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
  pinMode(11, OUTPUT);
}
```

Asta îi spune Arduino-ului: *"Hei! Pinii 9, 10 și 11 vor controla toți lumini!"*

</InfoBox>

<LessonChapter title="Pattern 1: Toate Împreună! 🎇" id="pattern-toate-impreuna">

Hai să facem toate cele trei lumini să clipească în același timp - ca artificii! 🎆

```cpp
void loop() {
  // Aprinde TOATE luminile împreună!
  digitalWrite(9, HIGH);
  digitalWrite(10, HIGH);
  digitalWrite(11, HIGH);
  delay(500);
  
  // Stinge TOATE luminile împreună!
  digitalWrite(9, LOW);
  digitalWrite(10, LOW);
  digitalWrite(11, LOW);
  delay(500);
}
```

<InfoBox type="tip">
  **Gândește-te așa:** Când zici "SARI!" toți prietenii tăi sar împreună! Când zici "STOP!" toți se opresc! 🤸
</InfoBox>

</LessonChapter>

<LessonChapter title="Pattern 2: Unul Câte Unul! 🐛" id="pattern-urmarire">

Acum hai să facem luminile să se aprindă una câte una - ca o omidă care se târăște! 🐛

<GifStep
  stepNumber={2}
  title="Pattern-ul de Urmărire"
  gifUrl="https://placehold.co/600x400/8b5cf6/white?text=Pattern+Urmarire"
  alt="LED-urile se aprind unul câte unul"
>
  Privește cum fiecare lumină își ia rândul: Mai întâi **9**, apoi **10**, apoi **11**, apoi de la început! E ca și cum joacă urmărește liderul!
</GifStep>

```cpp
void loop() {
  // Lumina 1 clipește
  digitalWrite(9, HIGH);
  delay(200);
  digitalWrite(9, LOW);
  
  // Lumina 2 clipește
  digitalWrite(10, HIGH);
  delay(200);
  digitalWrite(10, LOW);
  
  // Lumina 3 clipește
  digitalWrite(11, HIGH);
  delay(200);
  digitalWrite(11, LOW);
}
```

<InfoBox type="tip">
  **E ca o cursă de ștafetă!** 🏃 Lumina 1 aleargă, apoi dă ștafeta Luminii 2, apoi Luminii 3!
</InfoBox>

<LessonChapter title="Pattern 3: Înainte și Înapoi! 🏓" id="pattern-ping-pong">

Acum hai să facem luminile să meargă înainte și înapoi - ca o minge de ping-pong! 🏓

```cpp
void loop() {
  // Mergi înainte: 9 → 10 → 11
  digitalWrite(9, HIGH);
  delay(150);
  digitalWrite(9, LOW);
  
  digitalWrite(10, HIGH);
  delay(150);
  digitalWrite(10, LOW);
  
  digitalWrite(11, HIGH);
  delay(150);
  digitalWrite(11, LOW);
  
  // Mergi înapoi: 10 → 9
  digitalWrite(10, HIGH);
  delay(150);
  digitalWrite(10, LOW);
}
```

<InfoBox type="tip">
  **Boing boing boing!** Lumina sare de la un capăt la altul și înapoi, exact ca o minge! 🎾
</InfoBox>

</LessonChapter>

<LessonChapter title="Experimente Distractive! 🧪" id="experimente">

### Fă-le MAI RAPIDE! 🚀

Schimbă toate `delay(200)` cu `delay(50)`:
```cpp
delay(50);
```
Acum zboară super repede!

### Fă-le MAI LENTE! 🐢

Schimbă cu `delay(500)`:
```cpp
delay(500);
```
Frumos și încet, ca o omidă somnoroasă!

### Fă o BĂTAIE DE INIMĂ! ❤️

Încearcă acest pattern care arată ca o inimă care bate:
```cpp
// Bătaie rapidă dublă
digitalWrite(9, HIGH);
digitalWrite(10, HIGH);
digitalWrite(11, HIGH);
delay(100);
digitalWrite(9, LOW);
digitalWrite(10, LOW);
digitalWrite(11, LOW);
delay(100);

digitalWrite(9, HIGH);
digitalWrite(10, HIGH);
digitalWrite(11, HIGH);
delay(100);
digitalWrite(9, LOW);
digitalWrite(10, LOW);
digitalWrite(11, LOW);
delay(400);
```

<InfoBox type="tip">
  **Provocare:** Poți să faci un pattern care arată ca valurile oceanului? 🌊 Încearcă să aprinzi și să stingi luminile la momente diferite!
</InfoBox>

</LessonChapter>

### Ce ai învățat azi:

- ✅ Controlezi **3 LED-uri** în același timp

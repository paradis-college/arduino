<LessonChapter title="Controlul Mai Multor LED-uri" id="control-multiple">

### Metoda Lungă (Fără Array)

Poți controla fiecare LED individual:

```cpp
void setup() {
  pinMode(9, OUTPUT);   // Primul LED
  pinMode(10, OUTPUT);  // Al doilea LED
  pinMode(11, OUTPUT);  // Al treilea LED
}
```

Dar ce se întâmplă dacă ai 10 LED-uri? Sau 100? Ar trebui să scrii foarte multe linii! 😓

### Metoda Inteligentă - Cu Array-uri! 🧠

Un **array** este ca o cutie cu mai multe compartimente, fiecare având un număr:

```cpp
int piniiLED[] = {9, 10, 11};  // Array cu 3 numere de pini
int numarLED = 3;               // Câte LED-uri avem

void setup() {
  // Folosim o buclă pentru a configura TOATE LED-urile
  for (int i = 0; i < numarLED; i++) {
    pinMode(piniiLED[i], OUTPUT);
  }
}
```

<InfoBox type="info">
  **Pentru copii:** Imaginează-ți că ai un dulap cu 3 sertare numerotate 0, 1 și 2. În fiecare sertar ai pus un număr (9, 10, 11). Când vrei să folosești numărul din sertarul 0, spui `piniiLED[0]` și primești 9! 🗄️
</InfoBox>

### Cum Funcționează Bucla `for`?

```cpp
for (int i = 0; i < numarLED; i++) {
  // Codul de aici se execută de 3 ori
  // Prima dată: i = 0, deci piniiLED[0] = 9
  // A doua oară: i = 1, deci piniiLED[1] = 10
  // A treia oară: i = 2, deci piniiLED[2] = 11
}
```

<InfoBox type="tip">
  **Analogie pentru copii:** Bucla `for` este ca atunci când numeri: "unu, doi, trei". Faci același lucru de trei ori, dar de fiecare dată cu un număr diferit! 🔢
</InfoBox>

<LessonChapter title="Model: Toate Clipesc Împreună" id="toate-clipesc">

### Clipirea Simultană - Toate LED-urile Împreună

Acest model face toate LED-urile să se aprindă și să se stingă în același timp, ca la lumina de avertizare:

```cpp
void toateClipesc() {
  // Aprinde TOATE LED-urile
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], HIGH);
  }
  delay(500);  // Așteaptă jumătate de secundă
  
  // Stinge TOATE LED-urile
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], LOW);
  }
  delay(500);  // Așteaptă jumătate de secundă
}
```

<InfoBox type="tip">
  **Pentru copii:** Este ca și cum ai avea 3 lanterne și le aprinzi pe toate împreună, apoi le stingi pe toate împreună! 🔦🔦🔦
</InfoBox>

</LessonChapter>

<LessonChapter title="Model: Urmărire (Chase)" id="model-urmarire">

### Un LED pe Rând - Efect de Urmărire

Acest model aprinde câte un LED pe rând, creând un efect de "alergare":

```cpp
void modelUrmarire() {
  for (int i = 0; i < numarLED; i++) {
    // Aprinde LED-ul curent
    digitalWrite(piniiLED[i], HIGH);
    delay(200);  // Așteaptă puțin
    // Stinge LED-ul curent
    digitalWrite(piniiLED[i], LOW);
  }
}
```

<InfoBox type="info">
  **Pentru copii:** Este ca un joc de ștafetă! Primul LED se aprinde și "dă ștafeta" celui de-al doilea, apoi al doilea o dă celui de-al treilea. 🏃‍♂️➡️🏃‍♂️➡️🏃‍♂️
</InfoBox>

### Model Ping-Pong (Înainte și Înapoi)

Acest model merge într-o direcție, apoi se întoarce:

```cpp
void modelPingPong() {
  // Înainte: de la stânga la dreapta
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], HIGH);
    delay(150);
    digitalWrite(piniiLED[i], LOW);
  }
  
  // Înapoi: de la dreapta la stânga
  // Începem de la penultimul LED pentru a nu repeta ultimul
  for (int i = numarLED - 2; i > 0; i--) {
    digitalWrite(piniiLED[i], HIGH);
    delay(150);
    digitalWrite(piniiLED[i], LOW);
  }
}
```

<InfoBox type="tip">
  **Pentru copii:** Imaginează-ți o minge de ping-pong care sare de la un capăt la altul al mesei! 🏓
</InfoBox>

<LessonChapter title="Model: Alternativ" id="model-alternativ">

### LED-uri Care Se Schimbă - Unul DA, Unul NU

Acest model aprinde LED-urile în poziții pare, apoi în poziții impare:

```cpp
void modelAlternativ() {
  // LED-uri în poziții pare: 0 și 2 (adică pinii 9 și 11)
  for (int i = 0; i < numarLED; i += 2) {
    digitalWrite(piniiLED[i], HIGH);
  }
  for (int i = 1; i < numarLED; i += 2) {
    digitalWrite(piniiLED[i], LOW);
  }
  delay(300);
  
  // Acum inversăm: LED-uri în poziții impare
  for (int i = 0; i < numarLED; i += 2) {
    digitalWrite(piniiLED[i], LOW);
  }
  for (int i = 1; i < numarLED; i += 2) {
    digitalWrite(piniiLED[i], HIGH);
  }
  delay(300);
}
```

<InfoBox type="info">
  **Pentru copii:** Imaginează-ți că ești la un concert și publicul face "val" - o parte se ridică când cealaltă stă jos! 🌊
</InfoBox>

</LessonChapter>

<LessonChapter title="Programul Complet" id="program-complet">

### Codul Final cu Toate Modelele

```cpp
// Definim pinii și numărul de LED-uri
int piniiLED[] = {9, 10, 11};
int numarLED = 3;

void setup() {
  // Configurăm toți pinii ca OUTPUT
  for (int i = 0; i < numarLED; i++) {
    pinMode(piniiLED[i], OUTPUT);
  }
}

void loop() {
  // Poți schimba care model rulează!
  // modelUrmarire();
  // toateClipesc();
  modelPingPong();
}

// Funcția pentru urmărire
void modelUrmarire() {
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], HIGH);
    delay(200);
    digitalWrite(piniiLED[i], LOW);
  }
}

// Funcția pentru clipire simultană
void toateClipesc() {
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], HIGH);
  }
  delay(500);
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], LOW);
  }
  delay(500);
}

// Funcția pentru ping-pong
void modelPingPong() {
  for (int i = 0; i < numarLED; i++) {
    digitalWrite(piniiLED[i], HIGH);
    delay(150);
    digitalWrite(piniiLED[i], LOW);
  }
  for (int i = numarLED - 2; i > 0; i--) {
    digitalWrite(piniiLED[i], HIGH);
    delay(150);
    digitalWrite(piniiLED[i], LOW);
  }
}
```

<InfoBox type="warning">
  **Sfat:** Poți schimba modelul care rulează punând `//` în fața celorlalte modele din `loop()`. `//` înseamnă "ignoră această linie"!
</InfoBox>

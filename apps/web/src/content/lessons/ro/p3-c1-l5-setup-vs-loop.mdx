### Ce punem în setup()?

Lucruri pe care trebuie să le faci **O SINGURĂ DATĂ**:

```cpp
void setup() {
  pinMode(13, OUTPUT);     // Spune-i pinului 13 că e output - O DATĂ!
  Serial.begin(9600);      // Începe să vorbești cu computerul - O DATĂ!
  digitalWrite(13, HIGH);  // Aprinde lumina la start - O DATĂ!
}
```

### Exemple din Viața Reală 🏠

| În Viața Reală | În Arduino |
|----------------|------------|
| 👟 Îți pui pantofii (o dată) | pinMode(13, OUTPUT) |
| 📱 Pornești telefonul (o dată) | Serial.begin(9600) |
| 🎒 Îți faci ghiozdanul (o dată) | Setează valorile de start |

<InfoBox type="tip">
  **Ține minte:** setup() e ca trezitul și pregătitul. O faci doar O DATĂ înainte să înceapă ziua! ☀️
</InfoBox>

### Ce punem în loop()?

Lucruri care trebuie să se întâmple **IAR ȘI IAR**:

```cpp
void loop() {
  digitalWrite(13, HIGH);  // Lumină APRINSĂ
  delay(500);              // Așteaptă
  digitalWrite(13, LOW);   // Lumină STINSĂ
  delay(500);              // Așteaptă
  // Apoi începe din nou de sus! 🔄
}
```

### Exemple din Viața Reală 🔄

| În Viața Reală | În Arduino |
|----------------|------------|
| 💨 Respirat (iar și iar) | Clipește o lumină |
| ❤️ Bătaia inimii (iar și iar) | Verifică un buton |
| 🚶 Pași când mergi (iar și iar) | Citește un senzor |

<InfoBox type="tip">
  **Ține minte:** loop() e ca respiratul sau bătaia inimii - se întâmplă iar și iar fără să te gândești! 💓
</InfoBox>

<LessonChapter title="Imaginea Completă! 🎨" id="imaginea-completa">

Iată cum funcționează FIECARE program Arduino:

```
1. Arduino pornește! ⚡
2. setup() rulează O DATĂ 📦
3. loop() începe să ruleze... 🔄
   ↓ face lucruri
   ↓ face lucruri
   ↓ face lucruri
   ← se întoarce la începutul loop()
4. loop() rulează MEREU! ♾️
```

### Un Program Complet:

```cpp
void setup() {
  // Asta rulează O DATĂ la start!
  pinMode(13, OUTPUT);
  Serial.begin(9600);
  Serial.println("Arduino s-a trezit!");
}

void loop() {
  // Asta rulează MEREU!
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
  // Acum ne întoarcem la începutul loop()!
}
```

<LessonChapter title="Greșeli Comune! ❌→✅" id="greseli-comune">

### Greșeala 1: pinMode în loop() ❌

```cpp
// GREȘIT! ❌
void loop() {
  pinMode(13, OUTPUT);  // NU! Asta rulează iar și iar!
  digitalWrite(13, HIGH);
}

// CORECT! ✅
void setup() {
  pinMode(13, OUTPUT);  // DA! Doar o dată!
}
void loop() {
  digitalWrite(13, HIGH);
}
```

### Greșeala 2: Mesaje de o singură dată în loop() ❌

```cpp
// GREȘIT! ❌ - Asta printează "Pornesc..." MEREU!
void loop() {
  Serial.println("Pornesc...");
}

// CORECT! ✅ - Printează o dată în setup!
void setup() {
  Serial.begin(9600);
  Serial.println("Pornesc...");
}
```

  **Întreabă-te:** "Trebuie asta să se întâmple o dată sau iar și iar?" Asta îți spune ce cutie să folosești! 🤔
</InfoBox>

<LessonChapter title="Ai Reușit! 🏆" id="rezumat">

### Ce ai învățat azi:

- ✅ **setup()** rulează **O DATĂ** - pentru pregătire!
- ✅ **loop()** rulează **MEREU** - pentru acțiunea principală!
- ✅ Pune **pinMode()** în setup (se face doar o dată!)
- ✅ Pune **codul de clipire** în loop (trebuie să se repete!)
- ✅ Întreabă-te: "O dată sau mereu?" 🤔

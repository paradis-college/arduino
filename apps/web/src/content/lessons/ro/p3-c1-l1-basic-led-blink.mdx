- `delay()` - cum faci pauze între acțiuni

### Fiecare Program Arduino Are Două Funcții Speciale

Gândește-te la un program Arduino ca la o rețetă de bucătărie:

```cpp
void setup() {
  // Această parte rulează O SINGURĂ DATĂ când pornești Arduino
  // Este ca pregătirea ingredientelor înainte de a găti
  // Aici punem instrucțiuni de pregătire
}

void loop() {
  // Această parte se repetă MEREU, fără oprire
  // Este ca mișcarea de amestecare - continuă și continuă
  // Aici punem instrucțiunile principale
}
```

<InfoBox type="tip">
  **Pentru copii:** Imaginează-ți că `setup()` este momentul în care îți pregătești jucăriile înainte de joc, iar `loop()` este jocul în sine care continuă cât vrei tu să te joci! 🎮
</InfoBox>

<LessonChapter title="Funcția pinMode()" id="functia-pinmode">

### Configurarea Pinilor - Spune-i Arduino-ului Ce Să Facă!

Înainte de a folosi un pin, trebuie să-i spui Arduino-ului dacă pinul va fi folosit pentru a **trimite** semnale (OUTPUT) sau pentru a **primi** semnale (INPUT).

Este ca și cum ai pune o etichetă pe o cutie: "Aceasta este pentru trimis" sau "Aceasta este pentru primit"!

```cpp
pinMode(pin, mod);
```

- `pin`: Numărul pinului (de la 0 la 13 pentru pinii digitali)
- `mod`: `INPUT` (primește), `OUTPUT` (trimite), sau `INPUT_PULLUP` (primește cu rezistor special)

### Exemplu Simplu

```cpp
void setup() {
  pinMode(13, OUTPUT);  // Pinul 13 va trimite semnale - va controla LED-ul!
}
```

<InfoBox type="tip">
  **Analogie pentru copii:** `pinMode()` este ca atunci când îi spui prietenului tău "Tu vorbești, eu ascult!" sau "Eu vorbesc, tu asculți!". Arduino-ul trebuie să știe cine face ce! 🗣️👂
</InfoBox>

</LessonChapter>

<LessonChapter title="Funcția digitalWrite()" id="functia-digitalwrite">

### Cum Controlezi LED-ul - PORNIT sau OPRIT!

După ce ai configurat pinul ca OUTPUT, poți să-l controlezi:

```cpp
digitalWrite(pin, valoare);
```

- `pin`: Numărul pinului
- `valoare`: `HIGH` (5V, LED aprins 💡) sau `LOW` (0V, LED stins ⚫)

### Ce Înseamnă HIGH și LOW?

| Valoare | Ce Face | Voltaj | LED |
|---------|---------|--------|-----|
| `HIGH` | Trimite curent | 5V | Aprins 💡 |
| `LOW` | Nu trimite curent | 0V | Stins ⚫ |

### Exemplu

```cpp
digitalWrite(13, HIGH);  // Aprinde LED-ul! 💡
digitalWrite(13, LOW);   // Stinge LED-ul! ⚫
```

<InfoBox type="tip">
  **Pentru copii:** Gândește-te la `HIGH` ca la un întrerupător de lumină pus pe ON, și `LOW` ca la întrerupătorul pus pe OFF. Tu controlezi lumina! 💡
</InfoBox>

<LessonChapter title="Funcția delay()" id="functia-delay">

### Cum Faci Pauze - Așteaptă Un Pic!

Funcția `delay()` face Arduino-ul să aștepte înainte de a continua:

```cpp
delay(milisecunde);
```

- 1000 milisecunde = 1 secundă (poți număra "unu, elefant" 🐘)
- 500 milisecunde = 0.5 secunde (jumătate de secundă)
- 100 milisecunde = 0.1 secunde (foarte rapid!)

<InfoBox type="info">
  **Pentru copii:** O milisecundă este FOARTE rapidă - de 1000 de ori mai rapidă decât o secundă! Imaginează-ți că împarți o secundă în 1000 de bucățele mici. ⏱️
</InfoBox>

### Codul Complet pentru Clipire

Iată tot programul - doar 8 linii de cod magic! ✨

```cpp
void setup() {
  pinMode(13, OUTPUT);    // Pregătim pinul 13 pentru a trimite semnale
}

void loop() {
  digitalWrite(13, HIGH); // Aprinde LED-ul 💡
  delay(1000);            // Așteaptă 1 secundă
  digitalWrite(13, LOW);  // Stinge LED-ul ⚫
  delay(1000);            // Așteaptă 1 secundă
  // Apoi totul se repetă! ♻️
}
```

<InfoBox type="warning">
  **Important:** Nu uita `delay()` între `HIGH` și `LOW`! Fără pauze, LED-ul se va aprinde și stinge atât de repede încât ochii tăi nu vor vedea nicio schimbare - va părea că este tot timpul aprins!
</InfoBox>

### Provocări Distractive 🎯

Încearcă să modifici codul pentru diferite efecte:

**1. Clipire Rapidă (ca o licurici):**
```cpp
delay(100);  // Schimbă 1000 cu 100 pentru clipire rapidă!
```

**2. Clipire Lentă (ca un far):**
```cpp
delay(2000);  // Schimbă 1000 cu 2000 pentru clipire lentă
```

**3. Cod Morse pentru "SOS":**
```cpp
// S = trei scurte, O = trei lungi, S = trei scurte
// Încearcă să creezi acest model!
```

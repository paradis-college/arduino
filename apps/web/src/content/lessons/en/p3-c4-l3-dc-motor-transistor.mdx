<LessonChapter title="Why Use a Transistor?" id="why-transistor">

### Arduino Pin Limitations

- Arduino pins: ~20-40mA maximum
- Small DC motors: 100-500mA
- Larger motors: 1A or more

### The Solution

A transistor lets Arduino's small signal control a larger motor current from a separate power supply.

</LessonChapter>

<LessonChapter title="Circuit Wiring" id="circuit-wiring">

### Components Needed

- NPN transistor (TIP120 or 2N2222)
- Flyback diode (1N4001 or similar)
- Base resistor (1kΩ)
- DC motor
- External power supply (if motor needs >5V or high current)

### Wiring Diagram

```
Arduino PWM Pin → 1kΩ Resistor → Transistor Base
Motor (+) → Power Supply (+)
Motor (-) → Transistor Collector
Transistor Emitter → GND
Flyback Diode: Cathode to Motor(+), Anode to Motor(-)
```

<InfoBox type="warning">
  The flyback diode is critical! It protects the transistor from voltage spikes when the motor turns off.
</InfoBox>

</LessonChapter>

<LessonChapter title="PWM Speed Control" id="pwm-speed-control">

### Using analogWrite()

```cpp
const int MOTOR_PIN = 9;  // PWM pin

void setup() {
  pinMode(MOTOR_PIN, OUTPUT);
}

void loop() {
  // Full speed
  analogWrite(MOTOR_PIN, 255);
  delay(2000);
  
  // Half speed
  analogWrite(MOTOR_PIN, 127);
  delay(2000);
  
  // Quarter speed
  analogWrite(MOTOR_PIN, 64);
  delay(2000);
  
  // Stop
  analogWrite(MOTOR_PIN, 0);
  delay(2000);
}
```

### Speed with Potentiometer

```cpp
const int POT_PIN = A0;
const int MOTOR_PIN = 9;

void loop() {
  int potValue = analogRead(POT_PIN);
  int motorSpeed = map(potValue, 0, 1023, 0, 255);
  analogWrite(MOTOR_PIN, motorSpeed);
  delay(10);
}
```

<LessonChapter title="Code Example" id="code-example">

### Complete Motor Control

```cpp
const int MOTOR_PIN = 9;
const int POT_PIN = A0;
const int BUTTON_PIN = 2;

bool motorEnabled = false;

void setup() {
  pinMode(MOTOR_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  // Button toggles motor enable
  if (digitalRead(BUTTON_PIN) == LOW) {
    motorEnabled = !motorEnabled;
    delay(200);  // Debounce
  }
  
  if (motorEnabled) {
    int speed = map(analogRead(POT_PIN), 0, 1023, 0, 255);
    analogWrite(MOTOR_PIN, speed);
  } else {
    analogWrite(MOTOR_PIN, 0);
  }
}
```

<InfoBox type="tip">
  For bidirectional motor control (forward AND reverse), you'll need an H-bridge circuit or motor driver IC like the L298N.
</InfoBox>

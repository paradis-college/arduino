<LessonChapter title="Differential Drive Basics" id="differential-drive">

### How It Works

Two independently controlled motors:
- Both forward = Go straight
- Left faster than right = Turn right
- Right faster than left = Turn left
- Opposite directions = Spin in place

### Motor Control

```cpp
void moveForward() {
  digitalWrite(LEFT_FWD, HIGH);
  digitalWrite(LEFT_BWD, LOW);
  digitalWrite(RIGHT_FWD, HIGH);
  digitalWrite(RIGHT_BWD, LOW);
}

void turnLeft() {
  digitalWrite(LEFT_FWD, LOW);
  digitalWrite(LEFT_BWD, LOW);
  digitalWrite(RIGHT_FWD, HIGH);
  digitalWrite(RIGHT_BWD, LOW);
}

void turnRight() {
  digitalWrite(LEFT_FWD, HIGH);
  digitalWrite(LEFT_BWD, LOW);
  digitalWrite(RIGHT_FWD, LOW);
  digitalWrite(RIGHT_BWD, LOW);
}

void stop() {
  digitalWrite(LEFT_FWD, LOW);
  digitalWrite(LEFT_BWD, LOW);
  digitalWrite(RIGHT_FWD, LOW);
  digitalWrite(RIGHT_BWD, LOW);
}
```

<LessonChapter title="Line Following Logic" id="line-following">

### Two-Sensor Approach

| Left Sensor | Right Sensor | Action |
|-------------|--------------|--------|
| Black | Black | Forward |
| White | Black | Turn Right |
| Black | White | Turn Left |
| White | White | Search/Stop |

### Code

```cpp
void lineFollow() {
  bool leftOnLine = digitalRead(LEFT_SENSOR) == LOW;
  bool rightOnLine = digitalRead(RIGHT_SENSOR) == LOW;
  
  if (leftOnLine && rightOnLine) {
    moveForward();
  } else if (!leftOnLine && rightOnLine) {
    turnRight();
  } else if (leftOnLine && !rightOnLine) {
    turnLeft();
  } else {
    // Lost line - search or stop
    stop();
  }
}
```

</LessonChapter>

<LessonChapter title="Obstacle Avoidance Logic" id="obstacle-avoidance">

### Simple Algorithm

```cpp
const int OBSTACLE_DISTANCE = 20;  // cm

void obstacleAvoid() {
  int distance = readUltrasonic();
  
  if (distance > OBSTACLE_DISTANCE) {
    moveForward();
  } else {
    stop();
    delay(200);
    
    // Check left
    turnLeft();
    delay(300);
    int leftDistance = readUltrasonic();
    
    // Check right
    turnRight();
    delay(600);
    int rightDistance = readUltrasonic();
    
    // Turn toward more open direction
    if (leftDistance > rightDistance) {
      turnLeft();
      delay(600);
    }
    // Already facing right if right is better
  }
}
```

<InfoBox type="tip">
  Start with slow motor speeds. It's easier to tune behavior when the robot moves slowly and predictably!
</InfoBox>

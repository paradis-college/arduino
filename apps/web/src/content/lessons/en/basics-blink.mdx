<Chapter number={2} title="Wiring Diagram" id="wiring-diagram">

Connect the LED to pin 13 of the Arduino:

<StepWithGif stepNumber={1} title="Connect the LED anode" gifUrl="/images/lessons/step1-led-anode.gif" gifAlt="Connecting LED anode to pin 13">

Connect the **long leg (anode +)** of the LED to pin 13 on the Arduino. The anode is the positive terminal and is always the longer leg of the LED.

Make sure the connection is firm and the wire is properly inserted into the breadboard holes.

</StepWithGif>

<StepWithGif stepNumber={2} title="Connect the LED cathode to the resistor" gifUrl="/images/lessons/step2-led-resistor.gif" gifAlt="Connecting LED cathode to resistor">

Connect the **short leg (cathode -)** to the resistor. The cathode is the negative terminal and is always the shorter leg.

The resistor limits the current flowing through the LED to prevent it from burning out.

</StepWithGif>

<StepWithGif stepNumber={3} title="Connect the resistor to GND" gifUrl="/images/lessons/step3-gnd.gif" gifAlt="Connecting resistor to ground">

Connect the **other end of the resistor** to the GND (Ground) pin on the Arduino. This completes the circuit.

The current will flow from pin 13, through the LED, through the resistor, and back to ground.

</StepWithGif>

<InfoBox type="warning">
  Always use a resistor with an LED! Without a resistor, too much current can flow through the LED and permanently damage it.
</InfoBox>

<Chapter number={4} title="The Code" id="the-code">

```cpp
// Define the pin for the LED
const int LED_PIN = 13;

void setup() {
  // Set the pin as output
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Turn the LED on
  digitalWrite(LED_PIN, HIGH);
  
  // Wait for 1 second (1000 milliseconds)
  delay(1000);
  
  // Turn the LED off
  digitalWrite(LED_PIN, LOW);
  
  // Wait another second
  delay(1000);
}
```

### Understanding `pinMode(pin, mode)`

This function configures a pin as either input (INPUT) or output (OUTPUT).

- `pin` - the pin number
- `mode` - `INPUT` or `OUTPUT`

<Checkpoint id="checkpoint-1" lessonKey="en/basics-blink" label="I understand the pinMode() function" />

### Understanding `digitalWrite(pin, value)`

Writes a digital value (HIGH or LOW) to a pin.

- `HIGH` = 5V (LED on)
- `LOW` = 0V (LED off)

### Understanding `delay(ms)`

Pauses program execution for a specified number of milliseconds.

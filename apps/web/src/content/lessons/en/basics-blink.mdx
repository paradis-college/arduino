# Basic LED Blink

In this lesson, you'll learn how to turn an LED on and off using Arduino. This is your first step into the world of electronics and microcontroller programming!

## What You'll Learn

- How an LED works
- How to use the `pinMode()` function
- How to use the `digitalWrite()` function
- How to use the `delay()` function

<InfoBox type="info">
  An LED (Light Emitting Diode) is an electronic component that emits light when electric current passes through it.
</InfoBox>

## Required Components

For this project you'll need:

- 1x Arduino Uno
- 1x LED (any color)
- 1x 220Ω Resistor
- Jumper wires
- Breadboard

## Wiring Diagram

Connect the LED to pin 13 of the Arduino:

1. Connect the long leg (anode +) of the LED to pin 13
2. Connect the short leg (cathode -) to the resistor
3. Connect the other end of the resistor to GND

<InfoBox type="warning">
  Always use a resistor with an LED! Without a resistor, the LED can burn out.
</InfoBox>

## The Code

```cpp
// Define the pin for the LED
const int LED_PIN = 13;

void setup() {
  // Set the pin as output
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Turn the LED on
  digitalWrite(LED_PIN, HIGH);
  
  // Wait for 1 second (1000 milliseconds)
  delay(1000);
  
  // Turn the LED off
  digitalWrite(LED_PIN, LOW);
  
  // Wait another second
  delay(1000);
}
```

## Code Explanation

### `pinMode(pin, mode)`

This function configures a pin as either input (INPUT) or output (OUTPUT).

- `pin` - the pin number
- `mode` - `INPUT` or `OUTPUT`

<Checkpoint id="checkpoint-1" lessonKey="en/basics-blink" label="I understand the pinMode() function" />

### `digitalWrite(pin, value)`

Writes a digital value (HIGH or LOW) to a pin.

- `HIGH` = 5V (LED on)
- `LOW` = 0V (LED off)

### `delay(ms)`

Pauses program execution for a specified number of milliseconds.

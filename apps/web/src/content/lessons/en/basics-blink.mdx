<GifStep

<GifStep
  stepNumber={3}

  Connect the other end of the resistor to **GND** (Ground) on the Arduino. This completes the circuit, allowing current to flow from pin 13, through the LED, through the resistor, and back to ground.
</GifStep>

<InfoBox type="warning">
  Always use a resistor with an LED! Without a resistor, the LED can burn out.
</InfoBox>

<LessonChapter title="The Code" id="the-code">

```cpp
// Define the pin for the LED
const int LED_PIN = 13;

void setup() {
  // Set the pin as output
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Turn the LED on
  digitalWrite(LED_PIN, HIGH);
  
  // Wait for 1 second (1000 milliseconds)
  delay(1000);
  
  // Turn the LED off
  digitalWrite(LED_PIN, LOW);
  
  // Wait another second
  delay(1000);
}
```

</LessonChapter>

<LessonChapter title="Code Explanation" id="code-explanation">

### `pinMode(pin, mode)`

This function configures a pin as either input (INPUT) or output (OUTPUT).

- `pin` - the pin number
- `mode` - `INPUT` or `OUTPUT`

<Checkpoint id="checkpoint-1" lessonKey="en/basics-blink" label="I understand the pinMode() function" />

### `digitalWrite(pin, value)`

Writes a digital value (HIGH or LOW) to a pin.

- `HIGH` = 5V (LED on)
- `LOW` = 0V (LED off)

### `delay(ms)`

Pauses program execution for a specified number of milliseconds.

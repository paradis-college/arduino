### How It Works

A potentiometer has three pins:
1. **Pin 1**: Connect to 5V
2. **Pin 2 (Wiper)**: Connect to Arduino analog pin
3. **Pin 3**: Connect to GND

As you turn the knob, the wiper moves along a resistive element, dividing voltage between 0V and 5V.

### Wiring

```
Pot Pin 1 → 5V
Pot Pin 2 (middle) → A0
Pot Pin 3 → GND
```

<LessonChapter title="analogRead() Function" id="analogread-function">

### Reading Analog Values

```cpp
int value = analogRead(pin);
```

- Returns 0-1023 (10-bit resolution)
- 0 = 0V, 1023 = 5V
- Pins A0-A5 on Arduino Uno

### Example

```cpp
const int POT_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int potValue = analogRead(POT_PIN);
  Serial.println(potValue);
  delay(100);
}
```

<LessonChapter title="Mapping Values" id="mapping-values">

### The map() Function

Convert 0-1023 to other ranges:

```cpp
int newValue = map(value, fromLow, fromHigh, toLow, toHigh);
```

### Examples

```cpp
// Map to PWM range (0-255)
int brightness = map(potValue, 0, 1023, 0, 255);
analogWrite(LED_PIN, brightness);

// Map to servo angle (0-180)
int angle = map(potValue, 0, 1023, 0, 180);
myServo.write(angle);

// Map to percentage (0-100)
int percent = map(potValue, 0, 1023, 0, 100);
```

### Complete LED Brightness Control

```cpp
const int POT_PIN = A0;
const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int potValue = analogRead(POT_PIN);
  int brightness = map(potValue, 0, 1023, 0, 255);
  analogWrite(LED_PIN, brightness);
  delay(10);
}
```

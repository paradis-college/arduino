<LessonChapter title="Capacitive Touch Basics" id="capacitive-touch-basics">

### How It Works

1. Touch pad has a specific capacitance
2. Human body adds capacitance when touching
3. Sensor IC detects the change
4. Output switches HIGH or LOW

### TTP223 Module

Common, inexpensive touch sensor module:
- Single touch pad
- Digital output (HIGH when touched)
- 2.0-5.5V operating voltage
- Adjustable sensitivity

### Pin Configuration

| Pin | Function |
|-----|----------|
| VCC | 2-5.5V Power |
| GND | Ground |
| OUT/SIG | Digital Output |

<LessonChapter title="Reading Touch Input" id="reading-touch">

### Simple Code

```cpp
const int TOUCH_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(TOUCH_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int touched = digitalRead(TOUCH_PIN);
  
  if (touched == HIGH) {
    digitalWrite(LED_PIN, HIGH);
    Serial.println("Touched!");
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  delay(50);
}
```

### Toggle Mode

To toggle instead of momentary:

```cpp
bool ledState = false;
bool lastTouchState = LOW;

void loop() {
  bool currentTouch = digitalRead(TOUCH_PIN);
  
  if (currentTouch == HIGH && lastTouchState == LOW) {
    ledState = !ledState;
    digitalWrite(LED_PIN, ledState);
    delay(50);  // Simple debounce
  }
  
  lastTouchState = currentTouch;
}
```

<LessonChapter title="Advantages Over Buttons" id="advantages">

### Why Use Touch Sensors?

- **No moving parts**: Won't wear out
- **Sealed enclosures**: Touch through thin plastic
- **Modern look**: Sleek interfaces
- **Easy to clean**: Flat surface

### Considerations

- Need stable power supply
- Can be affected by moisture
- May trigger through thin gloves (or not)
- Electromagnetic interference sensitivity

<InfoBox type="tip">
  Touch sensors work great for control panels, light switches, and interactive displays where durability and aesthetics matter!
</InfoBox>

</LessonChapter>

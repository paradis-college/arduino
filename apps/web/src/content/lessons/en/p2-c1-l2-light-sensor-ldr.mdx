# Light Sensor (LDR)

In this lesson, you'll learn how to use a Light Dependent Resistor (LDR) to detect light levels and create light-responsive projects.

<LessonChapter title="What You'll Learn" id="what-youll-learn">

- LDR basics and voltage divider circuits
- Reading analog values (0-1023)
- Relationship between brightness and resistance
- Threshold-based control systems

<InfoBox type="info">
  An LDR (Light Dependent Resistor) changes its resistance based on light intensity - more light means lower resistance.
</InfoBox>

</LessonChapter>

<LessonChapter title="LDR Basics" id="ldr-basics">

### How LDRs Work

- **In darkness**: Resistance is HIGH (100kΩ - 1MΩ)
- **In bright light**: Resistance is LOW (1kΩ - 10kΩ)

### Voltage Divider Circuit

Since Arduino can only read voltage (not resistance), we create a voltage divider:

```
5V → [LDR] ─┬─→ [10kΩ Resistor] → GND
            │
            └─→ Analog Pin (A0)
```

The analog pin reads the voltage at the junction between the LDR and resistor. As light increases, LDR resistance drops, and voltage at the analog pin increases.

<LessonChapter title="Reading Analog Values" id="reading-analog">

### The analogRead() Function

```cpp
int lightValue = analogRead(A0);  // Returns 0-1023
```

- **0**: No voltage (dark)
- **1023**: Full 5V (bright)

### Example Code

```cpp
const int LDR_PIN = A0;
const int LED_PIN = 13;
const int DARK_THRESHOLD = 300;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int lightLevel = analogRead(LDR_PIN);
  Serial.println(lightLevel);
  
  if (lightLevel < DARK_THRESHOLD) {
    digitalWrite(LED_PIN, HIGH);  // Turn on LED when dark
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  delay(100);
}
```

<LessonChapter title="Threshold-Based Control" id="threshold-control">

### Setting Thresholds

Test your LDR to find good threshold values:
1. Cover the LDR completely - note the value (dark)
2. Shine a light on it - note the value (bright)
3. Choose threshold values in between

### Multiple Thresholds

```cpp
if (lightLevel < 200) {
  // Very dark - "Dark"
} else if (lightLevel < 600) {
  // Medium - "Dim"
} else {
  // Bright - "Bright"
}
```

<InfoBox type="tip">
  LDRs are perfect for automatic night lights, solar trackers, and ambient light-responsive displays!
</InfoBox>

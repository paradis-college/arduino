<LessonChapter title="GPIO Pin Numbering" id="gpio-numbering">

### Two Numbering Schemes

**BCM (Broadcom)**: GPIO numbers from the chip
- GPIO17, GPIO27, GPIO22...
- Used by gpiozero library

**BOARD**: Physical pin positions
- Pin 1, Pin 2, Pin 3...
- Sequential, easier to count

### Common GPIO Pins

| BCM | BOARD | Use |
|-----|-------|-----|
| GPIO17 | Pin 11 | General IO |
| GPIO27 | Pin 13 | General IO |
| GPIO22 | Pin 15 | General IO |
| GPIO5 | Pin 29 | General IO |
| GPIO6 | Pin 31 | General IO |

<InfoBox type="warning">
  Some pins have special functions! Always check the pinout before connecting hardware. Pins 1 and 17 are 3.3V, Pins 2 and 4 are 5V.
</InfoBox>

<LessonChapter title="gpiozero Library" id="gpiozero-library">

### Why gpiozero?

- Simple, beginner-friendly
- Pre-installed on Raspberry Pi OS
- Object-oriented design
- Handles cleanup automatically

### Basic LED Control

```python
from gpiozero import LED
from time import sleep

led = LED(17)  # BCM pin 17

led.on()
sleep(1)
led.off()
sleep(1)

# Or use blink!
led.blink(on_time=0.5, off_time=0.5)
```

<LessonChapter title="Button Input" id="button-input">

### Reading a Button

```python
from gpiozero import Button

button = Button(17)  # BCM pin 17

while True:
    if button.is_pressed:
        print("Button pressed!")
    else:
        print("Button released")
```

### Event-Based Approach

```python
from gpiozero import Button, LED
from signal import pause

button = Button(17)
led = LED(27)

button.when_pressed = led.on
button.when_released = led.off

pause()  # Keep program running
```

<InfoBox type="tip">
  gpiozero buttons use internal pull-ups by default, so you only need to connect button between GPIO and GND.
</InfoBox>

</LessonChapter>

<LessonChapter title="Complete Example" id="complete-example">

### LED Controlled by Button

```python
#!/usr/bin/env python3
from gpiozero import LED, Button
from signal import pause

# Setup
led = LED(17)
button = Button(27)

# Connect button to LED
button.when_pressed = led.on
button.when_released = led.off

print("Press the button to light the LED!")
print("Press Ctrl+C to exit")

pause()
```

Save as `button_led.py` and run with:
```bash
python3 button_led.py
```

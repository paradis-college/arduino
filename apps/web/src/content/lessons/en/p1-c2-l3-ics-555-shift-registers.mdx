### Astable Mode (Oscillator)

The 555 timer can generate a continuous square wave signal:

```
Pin 1: GND
Pin 2: Trigger (connect to pin 6)
Pin 3: Output (LED or speaker)
Pin 4: Reset (connect to VCC)
Pin 5: Control (0.01µF to GND)
Pin 6: Threshold (connect to pin 2)
Pin 7: Discharge
Pin 8: VCC (5-15V)
```

### Frequency Formula

```
Frequency = 1.44 / ((R1 + 2×R2) × C)
```

<InfoBox type="tip">
  The 555 is one of the most versatile ICs ever made. It can create timers, oscillators, PWM signals, and more!
</InfoBox>

### Expanding Outputs

Arduino has limited pins, but a shift register lets you control 8 outputs using only 3 pins!

### How It Works

1. **Data Pin**: Send bits one at a time
2. **Clock Pin**: Each pulse shifts the data in
3. **Latch Pin**: Transfer shifted data to outputs

### Pins

```
Pin 14 (DS): Serial data input
Pin 11 (SRCLK): Shift register clock
Pin 12 (RCLK): Storage register clock (latch)
Pin 13 (OE): Output enable (active LOW)
Pin 10 (SRCLR): Clear (active LOW, connect to VCC)
Pins 1-7, 15 (Q0-Q7): Parallel outputs
```

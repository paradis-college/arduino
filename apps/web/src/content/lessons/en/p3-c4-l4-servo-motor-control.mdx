<LessonChapter title="Servo vs DC Motor" id="servo-vs-dc">

### DC Motor

- Spins continuously
- Speed control (not position)
- Needs encoder for position feedback
- Simple wiring

### Servo Motor

- Moves to specific angle (0-180°)
- Built-in position feedback
- Three wires: power, ground, signal
- Holds position automatically

<LessonChapter title="Servo Wiring" id="servo-wiring">

### Three-Wire Connection

| Wire Color | Connection |
|------------|------------|
| Red/Orange | 5V (or external 5-6V) |
| Brown/Black | GND |
| Yellow/Orange/White | Signal (any digital pin) |

### Power Considerations

- Small servos: Can use Arduino 5V
- Multiple or large servos: Use external 5V power supply
- Always share ground between Arduino and external supply

<InfoBox type="warning">
  Large servos can draw 500mA+ and may cause Arduino to reset if powered from USB. Use external power for reliability!
</InfoBox>

</LessonChapter>

<LessonChapter title="Servo Library" id="servo-library">

### Basic Usage

```cpp
#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);  // Attach to pin 9
}

void loop() {
  myServo.write(0);    // Move to 0 degrees
  delay(1000);
  myServo.write(90);   // Move to 90 degrees
  delay(1000);
  myServo.write(180);  // Move to 180 degrees
  delay(1000);
}
```

### Key Functions

- `attach(pin)` - Connect servo to a pin
- `write(angle)` - Move to angle (0-180)
- `read()` - Get current angle
- `detach()` - Disconnect servo

<LessonChapter title="Mapping Input to Angle" id="mapping-input">

### Potentiometer Control

```cpp
#include <Servo.h>

Servo myServo;
const int POT_PIN = A0;

void setup() {
  myServo.attach(9);
}

void loop() {
  int potValue = analogRead(POT_PIN);
  int angle = map(potValue, 0, 1023, 0, 180);
  myServo.write(angle);
  delay(15);  // Small delay for servo to move
}
```

### Button Controlled Sweep

```cpp
if (digitalRead(BTN_LEFT) == LOW) {
  currentAngle = max(0, currentAngle - 5);
}
if (digitalRead(BTN_RIGHT) == LOW) {
  currentAngle = min(180, currentAngle + 5);
}
myServo.write(currentAngle);
```

</LessonChapter>

<LessonChapter title="Smooth Sweep" id="smooth-sweep">

### Gradual Movement

```cpp
void smoothSweep() {
  // Sweep from 0 to 180
  for (int angle = 0; angle <= 180; angle += 1) {
    myServo.write(angle);
    delay(15);
  }
  // Sweep back from 180 to 0
  for (int angle = 180; angle >= 0; angle -= 1) {
    myServo.write(angle);
    delay(15);
  }
}
```

<InfoBox type="tip">
  Smaller delay values make the servo move faster, but too fast may skip positions. 15ms is a good starting point.
</InfoBox>

</LessonChapter>

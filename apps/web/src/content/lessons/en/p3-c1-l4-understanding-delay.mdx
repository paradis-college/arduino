# Understanding delay() and Timing

In this lesson, you'll learn how `delay()` works, its impact on responsiveness, and get a preview of non-blocking timing techniques.

</InfoBox>

<LessonChapter title="How delay() Works" id="how-delay-works">

### Blocking Behavior

When `delay()` is called:
1. Arduino completely stops executing code
2. Waits for the specified time
3. Then continues to the next line

```cpp
void loop() {
  digitalWrite(13, HIGH);
  delay(5000);  // BLOCKED for 5 seconds!
  digitalWrite(13, LOW);
  delay(5000);  // BLOCKED again!
}
```

During those 5 seconds, Arduino can't:
- Read buttons
- Update sensors
- Respond to serial commands
- Do anything else!

### The Problem

```cpp
void loop() {
  // Check button - might miss presses!
  if (digitalRead(BUTTON_PIN) == LOW) {
    doSomething();
  }
  
  delay(2000);  // Button won't respond for 2 seconds!
}
```

### Visual Example

```
Time:    0s   1s   2s   3s   4s   5s
         |----delay----|----delay----|
Button:     X    X         X
         (missed!)  (missed!)   (detected!)
```

<InfoBox type="warning">
  Long delays make your project feel sluggish. Users expect immediate response to button presses!
</InfoBox>

</LessonChapter>

<LessonChapter title="Preview: Non-Blocking Timing" id="non-blocking-preview">

### The millis() Function

`millis()` returns milliseconds since Arduino started:

```cpp
unsigned long currentTime = millis();
```

### Blink Without Delay

```cpp
unsigned long previousMillis = 0;
const long interval = 1000;
int ledState = LOW;

void loop() {
  unsigned long currentMillis = millis();
  
  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;
    ledState = !ledState;
    digitalWrite(13, ledState);
  }
  
  // Other code runs freely here!
  checkButton();
  readSensors();
}
```

<LessonChapter title="When to Use Each" id="when-to-use">

### Use delay() When:

- Simple projects with one task
- Learning and testing
- Short delays (< 100ms) where responsiveness isn't critical

### Use millis() When:

- Multiple things need to happen
- Responsive input is needed
- Professional/production projects

<InfoBox type="tip">
  Start with delay() to understand timing, then learn millis() for more complex projects!
</InfoBox>

</LessonChapter>

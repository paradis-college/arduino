### First, Tell Arduino About All 3 Pins

Instead of writing three separate lines, we use a special trick!

```cpp
void setup() {
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
  pinMode(11, OUTPUT);
}
```

This tells Arduino: *"Hey! Pins 9, 10, and 11 will all control lights!"*

<InfoBox type="info">
  **For parents:** This lesson introduces the concept of controlling multiple outputs, which prepares for arrays in later lessons. For now, we keep it simple with three individual pins.
</InfoBox>

<LessonChapter title="Pattern 1: All Together! 🎇" id="pattern-all-together">

Let's make all three lights blink at the same time - like fireworks! 🎆

<P5SketchEmbed
  id="simultaneous-blink-animation"
  sketchId="p3-c1-l2-simultaneous-blink"
  stepNumber={2}
  title="All Lights Blink Together!"
  alt="Three LEDs blinking simultaneously"
>
  👀 **Look!** All three lights turn ON together, then OFF together! Like fireworks exploding in the sky! 🎆
</P5SketchEmbed>

```cpp
void loop() {
  // Turn ALL lights ON together!
  digitalWrite(9, HIGH);
  digitalWrite(10, HIGH);
  digitalWrite(11, HIGH);
  delay(500);

  // Turn ALL lights OFF together!
  digitalWrite(9, LOW);
  digitalWrite(10, LOW);
  digitalWrite(11, LOW);
  delay(500);
}
```

<InfoBox type="tip">
  **Think of it like:** When you say "JUMP!" all your friends jump together! When you say "STOP!" they all stop! 🤸
</InfoBox>

</LessonChapter>

<LessonChapter title="Pattern 2: One at a Time! 🐛" id="pattern-chase">

Now let's make the lights turn on one by one - like a caterpillar crawling! 🐛

<P5SketchEmbed
  id="chase-pattern-animation"
  sketchId="p3-c1-l2-chase-pattern"
  stepNumber={2}
  title="The Chase Pattern"
  alt="LEDs lighting up one by one"
>
  Watch as each light takes its turn: First **9**, then **10**, then **11**, then start over! It's like they're playing follow the leader!
</P5SketchEmbed>

```cpp
void loop() {
  // Light 1 blinks
  digitalWrite(9, HIGH);
  delay(200);
  digitalWrite(9, LOW);

  // Light 2 blinks
  digitalWrite(10, HIGH);
  delay(200);
  digitalWrite(10, LOW);

  // Light 3 blinks
  digitalWrite(11, HIGH);
  delay(200);
  digitalWrite(11, LOW);
}
```

<InfoBox type="tip">
  **It's like a relay race!** 🏃 Light 1 runs, then passes the baton to Light 2, then to Light 3!
</InfoBox>

<LessonChapter title="Pattern 3: Back and Forth! 🏓" id="pattern-ping-pong">

Now let's make the lights go back and forth - like a ping-pong ball! 🏓

```cpp
void loop() {
  // Go forward: 9 → 10 → 11
  digitalWrite(9, HIGH);
  delay(150);
  digitalWrite(9, LOW);

  digitalWrite(10, HIGH);
  delay(150);
  digitalWrite(10, LOW);

  digitalWrite(11, HIGH);
  delay(150);
  digitalWrite(11, LOW);

  // Go backward: 10 → 9
  digitalWrite(10, HIGH);
  delay(150);
  digitalWrite(10, LOW);
}
```

<InfoBox type="tip">
  **Bounce bounce bounce!** The light bounces from one end to the other and back, just like a ball! 🎾
</InfoBox>

</LessonChapter>

<LessonChapter title="Fun Experiments! 🧪" id="experiments">

### Make It FASTER! 🚀

Change all the `delay(200)` to `delay(50)`:
```cpp
delay(50);
```
Now they zoom around super fast!

### Make It SLOWER! 🐢

Change to `delay(500)`:
```cpp
delay(500);
```
Nice and slow, like a sleepy caterpillar!

### Make a HEARTBEAT! ❤️

Try this pattern that looks like a heart beating:
```cpp
// Quick double-beat
digitalWrite(9, HIGH);
digitalWrite(10, HIGH);
digitalWrite(11, HIGH);
delay(100);
digitalWrite(9, LOW);
digitalWrite(10, LOW);
digitalWrite(11, LOW);
delay(100);

digitalWrite(9, HIGH);
digitalWrite(10, HIGH);
digitalWrite(11, HIGH);
delay(100);
digitalWrite(9, LOW);
digitalWrite(10, LOW);
digitalWrite(11, LOW);
delay(400);
```

<LessonChapter title="Controlling Multiple LEDs" id="multiple-outputs">

### The Long Way (Without Arrays)

You could control each LED individually:

```cpp
void setup() {
  pinMode(9, OUTPUT);   // First LED
  pinMode(10, OUTPUT);  // Second LED
  pinMode(11, OUTPUT);  // Third LED
}
```

But what if you have 10 LEDs? Or 100? You'd have to write so many lines! 😓

### The Smart Way - With Arrays! 🧠

An **array** is like a box with multiple compartments, each with a number:

```cpp
int ledPins[] = {9, 10, 11};  // Array with 3 pin numbers
int numLeds = 3;              // How many LEDs we have

void setup() {
  // Use a loop to configure ALL LEDs
  for (int i = 0; i < numLeds; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}
```

<InfoBox type="info">
  **For kids:** Imagine you have a cabinet with 3 drawers numbered 0, 1, and 2. In each drawer you put a number (9, 10, 11). When you want to use the number from drawer 0, you say `ledPins[0]` and you get 9! 🗄️
</InfoBox>

### How Does the `for` Loop Work?

```cpp
for (int i = 0; i < numLeds; i++) {
  // The code here runs 3 times
  // First time: i = 0, so ledPins[0] = 9
  // Second time: i = 1, so ledPins[1] = 10
  // Third time: i = 2, so ledPins[2] = 11
}
```

<InfoBox type="tip">
  **For kids:** The `for` loop is like counting: "one, two, three". You do the same thing three times, but each time with a different number! 🔢
</InfoBox>

### Simultaneous Blink - All LEDs Together

This pattern makes all LEDs turn on and off at the same time, like a warning light:

```cpp
void allBlink() {
  // Turn ALL LEDs on
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], HIGH);
  }
  delay(500);  // Wait half a second
  
  // Turn ALL LEDs off
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], LOW);
  }
  delay(500);  // Wait half a second
}
```

<InfoBox type="tip">
  **For kids:** It's like having 3 flashlights and turning them all on together, then turning them all off together! 🔦🔦🔦
</InfoBox>

</LessonChapter>

<LessonChapter title="Chase Pattern" id="chase-pattern">

### One LED at a Time - Chase Effect

This pattern turns on one LED at a time, creating a "running" effect:

```cpp
void chasePattern() {
  for (int i = 0; i < numLeds; i++) {
    // Turn current LED on
    digitalWrite(ledPins[i], HIGH);
    delay(200);  // Wait a bit
    // Turn current LED off
    digitalWrite(ledPins[i], LOW);
  }
}
```

<InfoBox type="info">
  **For kids:** It's like a relay race! The first LED lights up and "passes the baton" to the second, then the second passes it to the third. 🏃‍♂️➡️🏃‍♂️➡️🏃‍♂️
</InfoBox>

### Ping-Pong Pattern (Back and Forth)

This pattern goes in one direction, then returns:

```cpp
void pingPongPattern() {
  // Forward: left to right
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], HIGH);
    delay(150);
    digitalWrite(ledPins[i], LOW);
  }
  
  // Backward: right to left
  // Start from the second-to-last LED to avoid repeating the last one
  for (int i = numLeds - 2; i > 0; i--) {
    digitalWrite(ledPins[i], HIGH);
    delay(150);
    digitalWrite(ledPins[i], LOW);
  }
}
```

<InfoBox type="tip">
  **For kids:** Imagine a ping-pong ball bouncing from one end of the table to the other! 🏓
</InfoBox>

<LessonChapter title="Alternate Pattern" id="alternate-pattern">

### LEDs That Take Turns - One YES, One NO

This pattern turns on LEDs in even positions, then odd positions:

```cpp
void alternatePattern() {
  // LEDs in even positions: 0 and 2 (pins 9 and 11)
  for (int i = 0; i < numLeds; i += 2) {
    digitalWrite(ledPins[i], HIGH);
  }
  for (int i = 1; i < numLeds; i += 2) {
    digitalWrite(ledPins[i], LOW);
  }
  delay(300);
  
  // Now reverse: LEDs in odd positions
  for (int i = 0; i < numLeds; i += 2) {
    digitalWrite(ledPins[i], LOW);
  }
  for (int i = 1; i < numLeds; i += 2) {
    digitalWrite(ledPins[i], HIGH);
  }
  delay(300);
}
```

<InfoBox type="info">
  **For kids:** Imagine you're at a concert and the crowd does "the wave" - one part stands up while the other sits down! 🌊
</InfoBox>

</LessonChapter>

<LessonChapter title="Complete Program" id="complete-program">

### Final Code with All Patterns

```cpp
// Define pins and number of LEDs
int ledPins[] = {9, 10, 11};
int numLeds = 3;

void setup() {
  // Configure all pins as OUTPUT
  for (int i = 0; i < numLeds; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void loop() {
  // You can change which pattern runs!
  // chasePattern();
  // allBlink();
  pingPongPattern();
}

// Function for chase
void chasePattern() {
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], HIGH);
    delay(200);
    digitalWrite(ledPins[i], LOW);
  }
}

// Function for simultaneous blink
void allBlink() {
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], HIGH);
  }
  delay(500);
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], LOW);
  }
  delay(500);
}

// Function for ping-pong
void pingPongPattern() {
  for (int i = 0; i < numLeds; i++) {
    digitalWrite(ledPins[i], HIGH);
    delay(150);
    digitalWrite(ledPins[i], LOW);
  }
  for (int i = numLeds - 2; i > 0; i--) {
    digitalWrite(ledPins[i], HIGH);
    delay(150);
    digitalWrite(ledPins[i], LOW);
  }
}
```

<InfoBox type="warning">
  **Tip:** You can change which pattern runs by putting `//` in front of the other patterns in `loop()`. `//` means "ignore this line"!
</InfoBox>

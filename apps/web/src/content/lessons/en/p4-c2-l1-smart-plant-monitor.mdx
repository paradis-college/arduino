# Project – Smart Plant Monitor

In this project, you'll build a smart plant monitoring system that tracks soil moisture and provides feedback through LEDs.

<LessonChapter title="Moisture Thresholds" id="moisture-thresholds">

### Calibration

First, find your sensor's range:
1. Sensor in dry air → Record value (e.g., 800)
2. Sensor in water → Record value (e.g., 300)
3. Sensor in moist soil → Record value (e.g., 500)

### Setting Thresholds

```cpp
const int DRY_THRESHOLD = 600;     // Below this = needs water
const int WET_THRESHOLD = 400;     // Above this = too wet
// Between = optimal moisture
```

<LessonChapter title="Code Structure" id="code-structure">

### Pin Definitions

```cpp
const int MOISTURE_PIN = A0;
const int LED_RED = 2;     // Dry - needs water
const int LED_YELLOW = 3;  // OK - monitor
const int LED_GREEN = 4;   // Well watered

const int DRY_THRESHOLD = 600;
const int WET_THRESHOLD = 400;
```

### Reading and Display

```cpp
void loop() {
  int moisture = analogRead(MOISTURE_PIN);
  
  // Turn off all LEDs first
  digitalWrite(LED_RED, LOW);
  digitalWrite(LED_YELLOW, LOW);
  digitalWrite(LED_GREEN, LOW);
  
  if (moisture > DRY_THRESHOLD) {
    // Too dry - needs water!
    digitalWrite(LED_RED, HIGH);
    Serial.println("🥀 Plant needs water!");
  } else if (moisture < WET_THRESHOLD) {
    // Well watered
    digitalWrite(LED_GREEN, HIGH);
    Serial.println("🌱 Plant is happy!");
  } else {
    // In between - OK
    digitalWrite(LED_YELLOW, HIGH);
    Serial.println("😊 Moisture OK");
  }
  
  Serial.print("Raw value: ");
  Serial.println(moisture);
  
  delay(5000);  // Check every 5 seconds
}
```

### Optional: Auto Watering

```cpp
const int PUMP_PIN = 5;

void waterPlant() {
  digitalWrite(PUMP_PIN, HIGH);
  delay(3000);  // Water for 3 seconds
  digitalWrite(PUMP_PIN, LOW);
  
  // Wait for water to soak in before next reading
  delay(10000);
}
```

<InfoBox type="warning">
  Be careful with automated watering! Add safeguards to prevent over-watering, like maximum daily watering time.
</InfoBox>

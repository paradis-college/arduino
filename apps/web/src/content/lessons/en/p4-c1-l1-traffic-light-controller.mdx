# Project – Traffic Light Controller

In this project, you'll build a complete traffic light intersection controller with timed phases and pedestrian button handling.

<LessonChapter title="What You'll Build" id="what-youll-build">

- A working traffic light with Red, Yellow, Green LEDs
- State-based timing logic
- Pedestrian crossing button
- Phase sequencing

<InfoBox type="info">
  Traffic lights are excellent examples of state machines - systems that transition between defined states based on timing and inputs!
</InfoBox>

</LessonChapter>

<LessonChapter title="State Machine Concept" id="state-machine">

### Traffic Light States

| State | Main Road | Side Road | Duration |
|-------|-----------|-----------|----------|
| 1 | GREEN | RED | 5 seconds |
| 2 | YELLOW | RED | 2 seconds |
| 3 | RED | RED | 1 second |
| 4 | RED | GREEN | 5 seconds |
| 5 | RED | YELLOW | 2 seconds |
| 6 | RED | RED | 1 second |
| (repeat) | | | |

### Pedestrian Interrupt

When button pressed during green phase:
1. Shorten green phase
2. Go to yellow immediately
3. All red for pedestrian crossing
4. Resume normal cycle

<LessonChapter title="Code Structure" id="code-structure">

### Pin Definitions

```cpp
// Main road lights
const int MAIN_RED = 2;
const int MAIN_YELLOW = 3;
const int MAIN_GREEN = 4;

// Side road lights
const int SIDE_RED = 5;
const int SIDE_YELLOW = 6;
const int SIDE_GREEN = 7;

// Pedestrian button
const int PED_BUTTON = 8;

int currentState = 1;
unsigned long stateStartTime;
bool pedestrianWaiting = false;
```

### State Timing

```cpp
const unsigned long STATE_TIMES[] = {
  0,     // Not used (states start at 1)
  5000,  // State 1: Main green
  2000,  // State 2: Main yellow
  1000,  // State 3: All red
  5000,  // State 4: Side green
  2000,  // State 5: Side yellow
  1000   // State 6: All red
};
```

### Main Loop

```cpp
void loop() {
  checkPedestrianButton();
  
  unsigned long elapsed = millis() - stateStartTime;
  unsigned long stateTime = STATE_TIMES[currentState];
  
  // Shorten green if pedestrian waiting
  if (pedestrianWaiting && (currentState == 1 || currentState == 4)) {
    stateTime = min(stateTime, 2000UL);
  }
  
  if (elapsed >= stateTime) {
    nextState();
  }
  
  updateLights();
}
```

# Buttons & Switches (Series vs Parallel)

In this lesson, you'll learn how buttons and switches work, and how connecting them in series or parallel creates different logic behaviors.

<LessonChapter title="What You'll Learn" id="what-youll-learn">

- How push buttons work (open/closed states)
- Series connections create AND logic
- Parallel connections create OR logic
- How to read simple logic from circuits

<InfoBox type="info">
  A push button is a momentary switch - it only makes contact while being pressed. When released, the circuit opens again.
</InfoBox>

</LessonChapter>

### Open vs Closed States

- **Open (not pressed)**: No current flows - circuit is broken
- **Closed (pressed)**: Current flows - circuit is complete

<LessonChapter title="Series Connection (AND Logic)" id="series-connection">

<GifStep
  stepNumber={2}
  title="Wire Buttons in Series"
  gifUrl="https://placehold.co/600x400/2563eb/white?text=Series+Buttons+GIF"
  alt="Wiring buttons in series"
>
  Connect the output of Button A to the input of Button B. Current must flow through both buttons to reach the LED.
</GifStep>

When buttons are connected in **series**, the LED only turns on when **ALL** buttons are pressed.

```
[Battery+] → [Button A] → [Button B] → [LED] → [Ground]
```

This creates **AND logic**:
| Button A | Button B | LED |
|----------|----------|-----|
| Open | Open | OFF |
| Open | Closed | OFF |
| Closed | Open | OFF |
| Closed | Closed | ON |

<InfoBox type="tip">
  Think of series buttons like security checkpoints - you must pass through ALL of them to reach the destination.
</InfoBox>

</LessonChapter>

<LessonChapter title="Parallel Connection (OR Logic)" id="parallel-connection">

<GifStep
  stepNumber={3}
  title="Wire Buttons in Parallel"
  gifUrl="https://placehold.co/600x400/2563eb/white?text=Parallel+Buttons+GIF"
  alt="Wiring buttons in parallel"
>
  Connect both buttons between the same two points. Either button can complete the circuit independently.
</GifStep>

When buttons are connected in **parallel**, the LED turns on when **ANY** button is pressed.

```
[Battery+] → [Button A] ─┬─ [LED] → [Ground]
            [Button B] ─┘
```

This creates **OR logic**:
| Button A | Button B | LED |
|----------|----------|-----|
| Open | Open | OFF |
| Open | Closed | ON |
| Closed | Open | ON |
| Closed | Closed | ON |

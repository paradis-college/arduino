<LessonChapter title="Bluetooth Modules" id="bluetooth-modules">

### HC-05 vs HC-06

| Feature | HC-05 | HC-06 |
|---------|-------|-------|
| Mode | Master & Slave | Slave only |
| Configuration | AT commands | Limited AT |
| Price | Slightly higher | Lower |
| Use case | Connect to other devices | Phone control |

### Wiring

```
HC-05/06:
  VCC → Arduino 5V
  GND → Arduino GND
  TXD → Arduino RX (Pin 0) or SoftwareSerial RX
  RXD → Arduino TX (Pin 1) or SoftwareSerial TX
         (Use voltage divider: 5V→3.3V!)
```

<InfoBox type="warning">
  HC-05/06 RXD pin is 3.3V! Use a voltage divider when connecting to Arduino's 5V TX pin.
</InfoBox>

<LessonChapter title="Pairing" id="pairing">

### Setup Steps

1. Power on Arduino with Bluetooth module
2. On phone: Enable Bluetooth
3. Scan for devices - find "HC-05" or "HC-06"
4. Pair with PIN: usually "1234" or "0000"
5. Connect using a Bluetooth terminal app

### Testing Connection

```cpp
void setup() {
  Serial.begin(9600);  // Match module baud rate
  Serial.println("Bluetooth Ready");
}

void loop() {
  if (Serial.available()) {
    char c = Serial.read();
    Serial.print("Received: ");
    Serial.println(c);
  }
}
```

<LessonChapter title="Serial Over Bluetooth" id="serial-over-bt">

### Using SoftwareSerial

```cpp
#include <SoftwareSerial.h>

SoftwareSerial BTSerial(10, 11);  // RX, TX

void setup() {
  Serial.begin(9600);
  BTSerial.begin(9600);
  Serial.println("Bluetooth Ready");
}

void loop() {
  // From phone to Arduino
  if (BTSerial.available()) {
    char c = BTSerial.read();
    Serial.print("BT: ");
    Serial.println(c);
    processCommand(c);
  }
  
  // From Arduino to phone
  if (Serial.available()) {
    BTSerial.write(Serial.read());
  }
}
```

### Simple Control Commands

```cpp
void processCommand(char cmd) {
  switch (cmd) {
    case '1': digitalWrite(LED_PIN, HIGH); break;
    case '0': digitalWrite(LED_PIN, LOW); break;
    case 'F': moveForward(); break;
    case 'B': moveBackward(); break;
    case 'S': stop(); break;
  }
}
```

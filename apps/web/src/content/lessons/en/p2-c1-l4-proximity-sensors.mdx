<LessonChapter title="Proximity vs Distance" id="proximity-vs-distance">

### Distance Sensors

- Measure exact distance to object
- Return a range of values (cm, mm)
- More complex processing needed
- Example: HC-SR04 ultrasonic

### Proximity Sensors

- Detect if object is within threshold
- Return simple binary output (near/far)
- Fast response, simple logic
- Example: IR proximity modules

<InfoBox type="tip">
  Use proximity sensors when you only need to know "is something there?" and don't need the actual distance.
</InfoBox>

<LessonChapter title="Threshold Detection" id="threshold-detection">

### How It Works

Proximity sensors have a built-in threshold:
1. Object enters detection range
2. Sensor output goes HIGH (or LOW depending on type)
3. Object leaves detection range
4. Sensor output returns to default state

### Adjustable Thresholds

Many modules have a potentiometer to adjust:
- **Detection distance**: How close object must be
- Some have separate high/low thresholds for hysteresis

### Hysteresis

To prevent rapid on/off switching at the boundary:
- Turn ON threshold: Object at 5cm
- Turn OFF threshold: Object at 6cm

This "dead zone" prevents jittering.

<LessonChapter title="Avoiding False Triggers" id="avoiding-false-triggers">

### Common Issues

1. **Ambient light interference**: Shield the sensor from sunlight
2. **Reflective surfaces**: Adjust sensitivity for shiny objects
3. **Color variations**: Dark objects may not reflect IR well
4. **Edge cases**: Objects at the exact threshold distance

### Best Practices

- Test with actual objects you'll be detecting
- Add software debouncing for noisy signals
- Use appropriate detection range (not too far)
- Consider environmental factors (dust, humidity)

<InfoBox type="warning">
  Different materials reflect IR differently. A white paper might trigger at 15cm, but black fabric might need to be 5cm away.
</InfoBox>

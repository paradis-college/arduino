### Components

- Arduino Uno
- IR receiver module (TSOP1838 or similar)
- Any IR remote control

### Wiring

```
IR Receiver:
  VCC → Arduino 5V
  GND → Arduino GND
  OUT → Arduino Pin 2
```

<LessonChapter title="Discovering Button Codes" id="discovering-codes">

### Code to Find Codes

```cpp
#include <IRremote.h>

const int IR_PIN = 2;

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_PIN, ENABLE_LED_FEEDBACK);
  Serial.println("IR Receiver Ready");
}

void loop() {
  if (IrReceiver.decode()) {
    Serial.print("Code: 0x");
    Serial.println(IrReceiver.decodedIRData.decodedRawData, HEX);
    Serial.print("Command: 0x");
    Serial.println(IrReceiver.decodedIRData.command, HEX);
    IrReceiver.resume();
  }
}
```

### Create a Code Map

Press each button and note the codes:
```cpp
// Example codes (yours will be different!)
#define BTN_POWER 0x45
#define BTN_UP    0x46
#define BTN_DOWN  0x47
#define BTN_LEFT  0x44
#define BTN_RIGHT 0x43
#define BTN_OK    0x40
```

<LessonChapter title="Mapping Codes to Actions" id="mapping-actions">

### Control LEDs and Motors

```cpp
#include <IRremote.h>

const int IR_PIN = 2;
const int LED_PIN = 13;
int brightness = 0;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  IrReceiver.begin(IR_PIN, ENABLE_LED_FEEDBACK);
}

void loop() {
  if (IrReceiver.decode()) {
    switch (IrReceiver.decodedIRData.command) {
      case 0x45:  // Power - toggle LED
        digitalWrite(LED_PIN, !digitalRead(LED_PIN));
        break;
        
      case 0x46:  // Up - increase brightness
        brightness = min(255, brightness + 25);
        analogWrite(LED_PIN, brightness);
        break;
        
      case 0x47:  // Down - decrease brightness
        brightness = max(0, brightness - 25);
        analogWrite(LED_PIN, brightness);
        break;
    }
    IrReceiver.resume();
  }
}
```

<InfoBox type="tip">
  Test your codes first, then build the switch statement. Different remotes have different codes!
</InfoBox>

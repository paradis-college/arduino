<LessonChapter title="Serial Basics" id="serial-basics">

### Setting Up Serial

```cpp
void setup() {
  Serial.begin(9600);  // Start serial at 9600 baud
  Serial.println("Arduino Ready!");
}
```

### Baud Rate

Baud rate = bits per second
- Both sender and receiver must match
- Common rates: 9600, 115200
- Higher = faster, but more error-prone

<LessonChapter title="Sending Data" id="sending-data">

### Print Functions

```cpp
Serial.print("Hello");      // No newline
Serial.println("World");    // With newline
Serial.print(42);           // Print number
Serial.println(3.14);       // Print float

// Formatted output
int temp = 25;
Serial.print("Temperature: ");
Serial.print(temp);
Serial.println("°C");
```

### Output

```
HelloWorld
42
3.14
Temperature: 25°C
```

<LessonChapter title="Receiving Data" id="receiving-data">

### Reading Characters

```cpp
void loop() {
  if (Serial.available() > 0) {
    char received = Serial.read();
    Serial.print("Received: ");
    Serial.println(received);
  }
}
```

### Reading Strings

```cpp
void loop() {
  if (Serial.available() > 0) {
    String message = Serial.readStringUntil('\n');
    Serial.print("Got: ");
    Serial.println(message);
    
    // React to commands
    if (message == "ON") {
      digitalWrite(LED_PIN, HIGH);
    } else if (message == "OFF") {
      digitalWrite(LED_PIN, LOW);
    }
  }
}
```

<InfoBox type="tip">
  Use Serial.readStringUntil('\\n') to read complete lines. Make sure Serial Monitor is set to "Newline" ending!
</InfoBox>

</LessonChapter>

<LessonChapter title="Simple Protocols" id="simple-protocols">

### Command:Value Format

```cpp
void processCommand(String cmd) {
  int colonPos = cmd.indexOf(':');
  if (colonPos > 0) {
    String command = cmd.substring(0, colonPos);
    String value = cmd.substring(colonPos + 1);
    
    if (command == "LED") {
      int brightness = value.toInt();
      analogWrite(LED_PIN, brightness);
    } else if (command == "SERVO") {
      int angle = value.toInt();
      servo.write(angle);
    }
  }
}
// Usage: "LED:128" sets LED to 50%, "SERVO:90" moves servo
```

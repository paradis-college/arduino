### Pin Configuration

| Pin | Function |
|-----|----------|
| VCC | 5V Power |
| GND | Ground |
| Trig | Trigger Input |
| Echo | Echo Output |

### How It Works

1. Send a 10µs HIGH pulse to **Trig** pin
2. Sensor emits 8 ultrasonic pulses at 40kHz
3. Sensor waits for echo
4. **Echo** pin goes HIGH for duration proportional to distance

### The Formula

```cpp
distance = (echo_time × speed_of_sound) / 2
```

Sound travels at ~343 m/s (or 0.0343 cm/µs). We divide by 2 because sound travels to the object AND back.

### Arduino Code

```cpp
long readDistance() {
  // Send trigger pulse
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  
  // Read echo duration
  long duration = pulseIn(ECHO_PIN, HIGH);
  
  // Calculate distance in cm
  return duration * 0.0343 / 2;
}
```

### Range

The HC-SR04 can measure distances from **2cm to 400cm** with reasonable accuracy.

<InfoBox type="warning">
  Soft materials (fabric, foam) may absorb sound and give poor readings. Hard surfaces work best.
</InfoBox>

# Linux Basics on Raspberry Pi

In this lesson, you'll learn the essential Linux commands needed to work with Raspberry Pi effectively.

<LessonChapter title="What You'll Learn" id="what-youll-learn">

- Booting and accessing your Pi
- Using the terminal
- Core commands: ls, cd, mkdir, nano
- File system navigation

<InfoBox type="info">
  Raspberry Pi runs Linux - a powerful, flexible operating system that gives you complete control over your computer!
</InfoBox>

</LessonChapter>

<LessonChapter title="First Boot" id="first-boot">

### Setting Up

1. Flash Raspberry Pi OS to SD card (use Raspberry Pi Imager)
2. Insert SD card into Pi
3. Connect keyboard, mouse, monitor
4. Power on with USB-C

### Accessing Terminal

- GUI: Click Terminal icon in taskbar
- SSH: `ssh pi@raspberrypi.local` (enable in settings first)

<LessonChapter title="Navigation Commands" id="navigation-commands">

### pwd - Print Working Directory

```bash
pwd
# Output: /home/pi
```

### ls - List Files

```bash
ls          # List files
ls -l       # Detailed list
ls -la      # Include hidden files
ls -lh      # Human-readable sizes
```

### cd - Change Directory

```bash
cd Documents      # Go to Documents folder
cd ..             # Go up one level
cd ~              # Go to home directory
cd /              # Go to root
```

<Checkpoint id="checkpoint-2" lessonKey="en/p6-c1-l1-linux-basics" label="I understand navigation commands" />

</LessonChapter>

<LessonChapter title="File Management" id="file-management">

### mkdir - Make Directory

```bash
mkdir projects           # Create folder
mkdir -p a/b/c          # Create nested folders
```

### cp - Copy

```bash
cp file.txt backup.txt   # Copy file
cp -r folder/ backup/    # Copy folder recursively
```

### mv - Move/Rename

```bash
mv old.txt new.txt       # Rename file
mv file.txt Documents/   # Move to folder
```

### rm - Remove

```bash
rm file.txt              # Delete file
rm -r folder/            # Delete folder
rm -rf folder/           # Force delete (careful!)
```

<InfoBox type="warning">
  rm -rf is powerful and permanent! There's no recycle bin. Double-check before pressing Enter!
</InfoBox>

</LessonChapter>

<LessonChapter title="Editing Files" id="editing-files">

### nano - Simple Text Editor

```bash
nano myfile.txt          # Open or create file
```

Inside nano:
- Type to edit
- `Ctrl+O` → Save (Write Out)
- `Ctrl+X` → Exit
- `Ctrl+K` → Cut line
- `Ctrl+U` → Paste line

### cat - Display File Contents

```bash
cat myfile.txt           # Show file contents
```

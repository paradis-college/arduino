# setup() vs loop()

In this lesson, you'll understand the fundamental structure of every Arduino program - when code runs once vs repeatedly.

<LessonChapter title="What You'll Learn" id="what-youll-learn">

- `setup()` runs once at startup
- `loop()` runs repeatedly forever
- Where to put initialization vs main logic
- Program flow visualization

<InfoBox type="info">

</InfoBox>

<LessonChapter title="The setup() Function" id="setup-function">

### Runs Once at Power-On

`setup()` executes exactly once when:
- Arduino is powered on
- Reset button is pressed
- New code is uploaded

### What Goes in setup()

- Pin mode configuration
- Serial communication initialization
- Library initialization
- Variable initial values
- One-time hardware setup

```cpp
void setup() {
  pinMode(13, OUTPUT);           // Configure pins
  Serial.begin(9600);            // Start serial
  lcd.begin(16, 2);              // Initialize LCD
  servo.attach(9);               // Attach servo
}
```

<LessonChapter title="The loop() Function" id="loop-function">

### Runs Repeatedly Forever

After `setup()` completes, `loop()` runs continuously:

```
Start → setup() → loop() → loop() → loop() → loop() → ...
                    ↑_________|
                    (forever)
```

### What Goes in loop()

- Reading sensors
- Checking buttons
- Updating outputs
- Main program logic
- Anything that needs to repeat

```cpp
void loop() {
  int sensorValue = analogRead(A0);  // Read sensor
  
  if (sensorValue > 500) {
    digitalWrite(13, HIGH);          // React
  } else {
    digitalWrite(13, LOW);
  }
}
```

<LessonChapter title="Common Mistakes" id="common-mistakes">

### Mistake 1: pinMode in loop()

```cpp
// BAD - wastes time reconfiguring every loop
void loop() {
  pinMode(13, OUTPUT);  // Don't do this!
  digitalWrite(13, HIGH);
}

// GOOD - configure once in setup
void setup() {
  pinMode(13, OUTPUT);
}
void loop() {
  digitalWrite(13, HIGH);
}
```

### Mistake 2: One-time actions in loop()

```cpp
// BAD - prints forever
void loop() {
  Serial.println("Program started!");  // Floods serial!
}

// GOOD - print once in setup
void setup() {
  Serial.begin(9600);
  Serial.println("Program started!");
}
```

<InfoBox type="tip">
  Ask yourself: "Does this need to happen once or repeatedly?" Put it in the appropriate function!
</InfoBox>

</LessonChapter>

# The Two Magic Boxes! 📦📦

Every Arduino program has TWO special boxes - one for "getting ready" and one for "doing it again and again!" Let's learn them!

- 📦 Learn about the **setup()** box (runs ONCE!)
- 🔄 Learn about the **loop()** box (runs FOREVER!)
- ✨ Understand where to put your code

### What goes in setup()?

Things you only need to do **ONE TIME**:

```cpp
void setup() {
  pinMode(13, OUTPUT);     // Tell pin 13 it's an output - ONCE!
  Serial.begin(9600);      // Start talking to computer - ONCE!
  digitalWrite(13, HIGH);  // Turn on light at start - ONCE!
}
```

| 👟 Put on shoes (once) | pinMode(13, OUTPUT) |
| 📱 Turn on your phone (once) | Serial.begin(9600) |
| 🎒 Pack your backpack (once) | Set starting values |

### What goes in loop()?

Things that need to happen **AGAIN AND AGAIN**:

```cpp
void loop() {
  digitalWrite(13, HIGH);  // Light ON
  delay(500);              // Wait
  digitalWrite(13, LOW);   // Light OFF
  delay(500);              // Wait
  // Then it starts over at the top! 🔄
}
```

|--------------|------------|
| 💨 Breathing (again and again) | Blink a light |
| ❤️ Heartbeat (again and again) | Check a button |
| 🚶 Walking steps (again and again) | Read a sensor |

<InfoBox type="tip">
  **Remember:** loop() is like breathing or your heartbeat - it happens over and over without you thinking about it! 💓

Here's how EVERY Arduino program works:

```
1. Arduino turns ON! ⚡
2. setup() runs ONE time 📦
3. loop() starts running... 🔄
   ↓ do stuff
   ↓ do stuff
   ↓ do stuff
   ← go back to start of loop()
4. loop() runs FOREVER! ♾️
```

### A Complete Program:

```cpp
void setup() {
  // This runs ONCE at the start!
  pinMode(13, OUTPUT);
  Serial.begin(9600);
  Serial.println("Arduino woke up!");
}

void loop() {
  // This runs FOREVER!
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
  // Now we go back to the start of loop()!
}
```

<LessonChapter title="Common Mistakes! ❌→✅" id="common-mistakes">

### Mistake 1: pinMode in loop() ❌

```cpp
// WRONG! ❌
void loop() {
  pinMode(13, OUTPUT);  // NO! This runs over and over!
  digitalWrite(13, HIGH);
}

// CORRECT! ✅
void setup() {
  pinMode(13, OUTPUT);  // YES! Only once!
}
void loop() {
  digitalWrite(13, HIGH);
}
```

### Mistake 2: One-time messages in loop() ❌

```cpp
// WRONG! ❌ - This prints "Starting..." FOREVER!
void loop() {
  Serial.println("Starting...");
}

// CORRECT! ✅ - Print once in setup!
void setup() {
  Serial.begin(9600);
  Serial.println("Starting...");
}
```

<InfoBox type="warning">
  **Ask yourself:** "Does this need to happen once or over and over?" That tells you which box to use! 🤔
</InfoBox>

</LessonChapter>

- ✅ Put **blinking code** in loop (needs to repeat!)

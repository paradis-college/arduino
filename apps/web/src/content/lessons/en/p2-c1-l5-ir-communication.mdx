<LessonChapter title="IR Components" id="ir-components">

### IR LED (Transmitter)

- Looks like a clear or dark purple LED
- Emits infrared light (940nm typically)
- Driven like a regular LED with current-limiting resistor
- Used in remotes to send commands

### IR Receiver Module

- Contains photodiode + amplifier + filter
- Tuned to 38kHz modulation frequency
- Outputs demodulated digital signal
- Common modules: TSOP1838, VS1838B

<LessonChapter title="Modulated IR Signals" id="modulated-signals">

### Why Modulation?

IR from the sun and lights is everywhere. To distinguish signal from noise:
1. IR LED is rapidly switched on/off at 38kHz
2. Receiver only responds to 38kHz signals
3. Ambient IR is filtered out

### Signal Structure

Remote signals contain:
- **Start pulse**: Long burst to indicate start
- **Address bits**: Device ID (TV, AC, etc.)
- **Command bits**: Button code
- **Stop/repeat**: End marker

### Common Protocols

- **NEC**: Most common, used by many devices
- **Sony SIRC**: Sony devices
- **RC5/RC6**: Philips protocol

<LessonChapter title="Reading Remote Codes" id="reading-codes">

### Using IRremote Library

```cpp
#include <IRremote.h>

const int IR_PIN = 2;
IRrecv irrecv(IR_PIN);

void setup() {
  Serial.begin(9600);
  irrecv.enableIRIn();
}

void loop() {
  if (irrecv.decode()) {
    Serial.print("Code: 0x");
    Serial.println(irrecv.decodedIRData.decodedRawData, HEX);
    irrecv.resume();
  }
}
```

### Mapping Codes to Actions

```cpp
switch (irrecv.decodedIRData.command) {
  case 0x45:  // Power button
    togglePower();
    break;
  case 0x46:  // Volume Up
    volumeUp();
    break;
  // Add more buttons...
}
```

<InfoBox type="tip">
  Point your remote at the receiver and press buttons while watching Serial Monitor to discover each button's code!
</InfoBox>

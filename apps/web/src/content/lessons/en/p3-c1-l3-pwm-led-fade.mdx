<LessonChapter title="The New Magic Word: analogWrite! ✨" id="analogwrite">

Instead of `digitalWrite`, we use `analogWrite`!

```cpp
analogWrite(pin, brightness);
```

- **pin** = Which light (use pins with a ~ symbol: 3, 5, 6, 9, 10, 11)
- **brightness** = Pick a number from 0 to 255

### Try These! 

```cpp
analogWrite(9, 0);    // Light is OFF
analogWrite(9, 50);   // Light is DIM (like a nightlight)
analogWrite(9, 127);  // Light is MEDIUM
analogWrite(9, 255);  // Light is SUPER BRIGHT!
```

<InfoBox type="warning">
  **Important!** Only some pins work with `analogWrite`. Look for the little ~ symbol on your Arduino next to pins **3, 5, 6, 9, 10, and 11**!
</InfoBox>

</LessonChapter>

### Fade IN (0 → 255) - Getting Brighter! ☀️

```cpp
for (int i = 0; i <= 255; i = i + 5) {
  analogWrite(9, i);
  delay(30);
}
```

This makes `i` go from 0 to 255, step by step, making the light brighter!

### Fade OUT (255 → 0) - Getting Dimmer! 🌙

```cpp
for (int i = 255; i >= 0; i = i - 5) {
  analogWrite(9, i);
  delay(30);
}
```

This makes `i` go from 255 back to 0, making the light dimmer!

<InfoBox type="tip">
  **Don't worry about the `for` loop yet!** Just know it makes numbers go up (fade in) or down (fade out) automatically! 🔄
</InfoBox>

<LessonChapter title="The Complete Program! 🎉" id="complete-program">

Here's everything together:

```cpp
void setup() {
  pinMode(9, OUTPUT);
}

void loop() {
  // Fade IN - get brighter!
  for (int i = 0; i <= 255; i = i + 5) {
    analogWrite(9, i);
    delay(30);
  }
  
  // Fade OUT - get dimmer!
  for (int i = 255; i >= 0; i = i - 5) {
    analogWrite(9, i);
    delay(30);
  }
}
```

<InfoBox type="tip">
  **Upload it!** Watch your LED slowly breathe in and out! 😮‍💨✨
</InfoBox>

### Breathe FASTER! 🏃

Change `delay(30)` to `delay(10)`:
```cpp
delay(10);
```
Now it breathes fast like after running!

### Breathe SLOWER! 🧘

Change `delay(30)` to `delay(50)`:
```cpp
delay(50);
```
Nice and relaxed, like yoga breathing!

### Make a CANDLE Flicker! 🕯️

Random brightness for a spooky candle effect:
```cpp
void loop() {
  analogWrite(9, random(100, 255));
  delay(100);
}
```

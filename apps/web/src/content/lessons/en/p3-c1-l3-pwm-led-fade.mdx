<LessonChapter title="What is PWM?" id="what-is-pwm">

### Pulse Width Modulation

PWM rapidly switches between HIGH and LOW:
- **Duty cycle**: Percentage of time the signal is HIGH
- 0% = always LOW (LED off)
- 50% = half HIGH, half LOW (half brightness)
- 100% = always HIGH (full brightness)

### PWM Pins on Arduino Uno

Only certain pins support PWM (marked with ~):
- **Pins 3, 5, 6, 9, 10, 11**

<InfoBox type="warning">
  Pin 13 does NOT support PWM! Use pins 3, 5, 6, 9, 10, or 11 for analogWrite().
</InfoBox>

<LessonChapter title="analogWrite() Function" id="analogwrite-function">

### Syntax

```cpp
analogWrite(pin, value);
```

- `pin`: A PWM-capable pin (~)
- `value`: 0 to 255
  - 0 = 0% duty cycle (off)
  - 127 = ~50% duty cycle
  - 255 = 100% duty cycle (full on)

### Example

```cpp
const int LED_PIN = 9;  // Must be a PWM pin

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  analogWrite(LED_PIN, 64);   // 25% brightness
  delay(1000);
  analogWrite(LED_PIN, 127);  // 50% brightness
  delay(1000);
  analogWrite(LED_PIN, 255);  // 100% brightness
  delay(1000);
}
```

<LessonChapter title="Fade Effects" id="fade-effects">

### Fade In and Out

```cpp
const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Fade in
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(LED_PIN, brightness);
    delay(30);
  }
  
  // Fade out
  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(LED_PIN, brightness);
    delay(30);
  }
}
```

### Adjusting Speed

- Smaller `delay()` = faster fade
- Larger step size = choppier transition
- Smaller step size = smoother transition

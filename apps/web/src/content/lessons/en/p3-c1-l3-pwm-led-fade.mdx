<LessonChapter title="What is PWM?" id="what-is-pwm">

### Pulse Width Modulation - Simple Explanation

PWM rapidly switches between HIGH and LOW:
- **Duty cycle**: Percentage of time the signal is HIGH
- 0% = always LOW (LED off ⚫)
- 50% = half HIGH, half LOW (medium brightness 🔆)
- 100% = always HIGH (full brightness 💡)

<InfoBox type="tip">
  **For kids:** Imagine you have a flashlight and you turn it on and off VERY fast. If you keep it on more time than off, it looks brighter! If you keep it off more than on, it looks dimmer. PWM does exactly this, but thousands of times per second! 🔦⚡
</InfoBox>

### How It Works

```
100% (HIGH all the time):  ████████████████████
 75% (3/4 HIGH):           ████████████████░░░░
 50% (half HIGH):          ████████████░░░░░░░░
 25% (1/4 HIGH):           ██████░░░░░░░░░░░░░░
  0% (LOW all the time):   ░░░░░░░░░░░░░░░░░░░░

█ = HIGH (5V)   ░ = LOW (0V)
```

### PWM Pins on Arduino Uno

Only certain pins support PWM (they're marked with ~):
- **Pins 3, 5, 6, 9, 10, 11**

Look for the **~** (tilde) symbol next to the pin number on the Arduino board!

<InfoBox type="warning">
  Pin 13 does NOT support PWM! If you want to control brightness, use pins 3, 5, 6, 9, 10, or 11 for analogWrite().
</InfoBox>

<LessonChapter title="analogWrite() Function" id="analogwrite-function">

### Syntax

```cpp
analogWrite(pin, value);
```

- `pin`: A PWM-capable pin (marked with ~)
- `value`: From 0 to 255
  - **0** = 0% duty cycle (completely off)
  - **127** = ~50% duty cycle (medium brightness)
  - **255** = 100% duty cycle (full brightness)

### Value Reference Table

| Value | Duty Cycle | Brightness |
|-------|------------|------------|
| 0 | 0% | Off ⚫ |
| 64 | 25% | Dim 🌑 |
| 127 | 50% | Medium 🔆 |
| 191 | 75% | Bright 💡 |
| 255 | 100% | Maximum ☀️ |

### Example

```cpp
const int LED_PIN = 9;  // Must be a PWM pin

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  analogWrite(LED_PIN, 64);   // 25% brightness - like a night light
  delay(1000);
  analogWrite(LED_PIN, 127);  // 50% brightness - medium
  delay(1000);
  analogWrite(LED_PIN, 255);  // 100% brightness - bright!
  delay(1000);
}
```

<InfoBox type="tip">
  **For kids:** Think of the 0-255 values like a dimmer (brightness knob) that some people have at home. You can turn the knob to make the light dimmer or brighter! 🎛️
</InfoBox>

<LessonChapter title="Fade Effects" id="fade-effects">

### Fade In and Out - Breathing Light

This code makes the LED grow and fade in brightness, like it's breathing:

```cpp
const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Fade In - brightness increases gradually
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(LED_PIN, brightness);
    delay(30);  // Small pause between changes
  }
  
  // Fade Out - brightness decreases gradually
  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(LED_PIN, brightness);
    delay(30);  // Small pause between changes
  }
}
```

<InfoBox type="info">
  **How it works:** The `for` loop increases the `brightness` value from 0 to 255 in steps of 5. At each step, it updates the LED with the new value. The 30ms pauses make the transition visible and smooth!
</InfoBox>

### Adjusting Speed

- **Smaller delay()** = faster fade
- **Larger step** (e.g., `+= 10`) = less smooth, but faster transition
- **Smaller step** (e.g., `+= 1`) = very smooth, but slower transition

<InfoBox type="tip">
  **For kids:** It's like filling a cup with water - you can pour a lot quickly, or a little bit at a time. The LED "fills up" with light in the same way! 🥛💡
</InfoBox>

</LessonChapter>

<LessonChapter title="RGB LED - Mix Colors!" id="rgb-led">

### Create Any Color!

An RGB LED actually contains 3 LEDs in one: Red, Green, and Blue. By controlling the brightness of each with PWM, you can create millions of colors!

```cpp
const int RED_PIN = 9;
const int GREEN_PIN = 10;
const int BLUE_PIN = 11;

void setup() {
  pinMode(RED_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(BLUE_PIN, OUTPUT);
}

void setColor(int r, int g, int b) {
  analogWrite(RED_PIN, r);
  analogWrite(GREEN_PIN, g);
  analogWrite(BLUE_PIN, b);
}

void loop() {
  setColor(255, 0, 0);     // Pure red 🔴
  delay(1000);
  setColor(0, 255, 0);     // Pure green 🟢
  delay(1000);
  setColor(0, 0, 255);     // Pure blue 🔵
  delay(1000);
  setColor(255, 255, 0);   // Yellow (Red + Green) 🟡
  delay(1000);
  setColor(255, 0, 255);   // Magenta (Red + Blue) 🟣
  delay(1000);
  setColor(0, 255, 255);   // Cyan (Green + Blue) 🩵
  delay(1000);
  setColor(255, 255, 255); // White (all colors) ⚪
  delay(1000);
}
```

<InfoBox type="info">
  **For kids:** It's like mixing paints! Red + Yellow = Orange. With RGB LEDs, you can do the same thing with light! 🎨
</InfoBox>

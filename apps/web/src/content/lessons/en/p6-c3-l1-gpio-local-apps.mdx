<LessonChapter title="Event-Driven Design" id="event-driven-design">

### Callbacks vs Polling

**Polling** (less efficient):
```python
while True:
    if button.is_pressed:
        do_something()
    sleep(0.1)
```

**Event-driven** (better):
```python
button.when_pressed = do_something
pause()  # CPU efficient
```

### Multiple Events

```python
from gpiozero import Button
from signal import pause

button = Button(17)

def on_press():
    print("Pressed!")
    log_event("button_press")

def on_release():
    print("Released!")

button.when_pressed = on_press
button.when_released = on_release

pause()
```

### Logging to File

```python
from gpiozero import Button
from datetime import datetime
from signal import pause

button = Button(17)

def log_press():
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    with open("button_log.txt", "a") as f:
        f.write(f"{timestamp} - Button pressed\n")
    print(f"Logged: {timestamp}")

button.when_pressed = log_press
pause()
```

### Sensor Data Logging

```python
from gpiozero import MCP3008  # ADC for analog sensors
from datetime import datetime
from time import sleep
import csv

sensor = MCP3008(channel=0)

with open("sensor_data.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["timestamp", "value"])

    while True:
        timestamp = datetime.now().isoformat()
        value = sensor.value
        writer.writerow([timestamp, value])
        print(f"{timestamp}: {value:.3f}")
        sleep(1)
```

<LessonChapter title="Simple GUI Integration" id="gui-integration">

### Using Tkinter

```python
from gpiozero import LED, Button
import tkinter as tk

led = LED(17)
hw_button = Button(27)

# Create window
root = tk.Tk()
root.title("GPIO Control")

# Status label
status = tk.Label(root, text="LED: OFF", font=("Arial", 24))
status.pack(pady=20)

# Control buttons
def turn_on():
    led.on()
    status.config(text="LED: ON")

def turn_off():
    led.off()
    status.config(text="LED: OFF")

tk.Button(root, text="ON", command=turn_on).pack(side="left", padx=10)
tk.Button(root, text="OFF", command=turn_off).pack(side="right", padx=10)

# Hardware button updates GUI
def hw_pressed():
    root.after(0, lambda: status.config(text="HW Button Pressed!"))

hw_button.when_pressed = hw_pressed

root.mainloop()
```

<InfoBox type="tip">
  Tkinter comes pre-installed with Python. For more advanced UIs, consider PyQt5 or Kivy.
</InfoBox>

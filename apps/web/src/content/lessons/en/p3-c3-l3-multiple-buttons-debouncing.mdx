<LessonChapter title="Multiple Button Inputs" id="multiple-buttons">

### Wiring Multiple Buttons

Each button uses one digital pin with INPUT_PULLUP:

```cpp
const int BTN_1 = 2;
const int BTN_2 = 3;
const int BTN_3 = 4;

void setup() {
  pinMode(BTN_1, INPUT_PULLUP);
  pinMode(BTN_2, INPUT_PULLUP);
  pinMode(BTN_3, INPUT_PULLUP);
}
```

### Using Arrays

```cpp
const int buttonPins[] = {2, 3, 4, 5};
const int numButtons = 4;

void setup() {
  for (int i = 0; i < numButtons; i++) {
    pinMode(buttonPins[i], INPUT_PULLUP);
  }
}
```

<LessonChapter title="The Bouncing Problem" id="bouncing-problem">

### What Happens When You Press a Button

When a button is pressed, the metal contacts don't make a clean connection immediately. They "bounce" - rapidly connecting and disconnecting for 1-50 milliseconds.

```
What you think:  ____/‾‾‾‾‾‾‾‾‾‾
What happens:    ____/‾\_/‾\_/‾‾‾‾
                     ↑↑↑↑↑
                   (bounces!)
```

### The Result

Without debouncing:
- One press might register as 2-10 presses!
- Counters increment randomly
- Toggle switches flicker

<InfoBox type="warning">
  Bouncing happens so fast you can't see it, but Arduino is fast enough to detect every bounce!
</InfoBox>

</LessonChapter>

<LessonChapter title="Software Debouncing" id="software-debouncing">

### Simple Delay Debounce

```cpp
bool buttonPressed = false;

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW && !buttonPressed) {
    buttonPressed = true;
    handleButtonPress();  // Your action
    delay(50);  // Wait for bouncing to settle
  }
  
  if (digitalRead(BUTTON_PIN) == HIGH) {
    buttonPressed = false;
  }
}
```

### Better: Time-Based Debounce

```cpp
unsigned long lastDebounceTime = 0;
const unsigned long debounceDelay = 50;
int lastButtonState = HIGH;
int buttonState;

void loop() {
  int reading = digitalRead(BUTTON_PIN);
  
  if (reading != lastButtonState) {
    lastDebounceTime = millis();
  }
  
  if ((millis() - lastDebounceTime) > debounceDelay) {
    if (reading != buttonState) {
      buttonState = reading;
      if (buttonState == LOW) {
        // Button was pressed!
        handleButtonPress();
      }
    }
  }
  lastButtonState = reading;
}
```

Think of an Arduino program like a cooking recipe:

```cpp

  // This part runs ONCE when you turn on Arduino
  // It's like preparing ingredients before cooking
  // Put preparation instructions here
}

void loop() {
  // This part runs FOREVER, without stopping
  // It's like the stirring motion - it keeps going and going
  // Put your main instructions here
}
```

### Configuring Pins - Tell Arduino What To Do!

Before using a pin, you need to tell Arduino if the pin will be used to **send** signals (OUTPUT) or **receive** signals (INPUT).

It's like putting a label on a box: "This one is for sending" or "This one is for receiving"!

```cpp
pinMode(pin, mode);
```

- `pin`: The pin number (0-13 for digital pins)
- `mode`: `INPUT` (receive), `OUTPUT` (send), or `INPUT_PULLUP` (receive with special resistor)

### Example

```cpp
void setup() {
  pinMode(13, OUTPUT);  // Pin 13 will send signals - it will control the LED!
}
```

<InfoBox type="tip">
  **For kids:** `pinMode()` is like telling your friend "You talk, I listen!" or "I talk, you listen!". Arduino needs to know who does what! 🗣️👂
</InfoBox>

</LessonChapter>

<LessonChapter title="digitalWrite() Function" id="digitalwrite-function">

### How to Control the LED - ON or OFF!

After configuring the pin as OUTPUT, you can control it:

```cpp
digitalWrite(pin, value);
```

- `pin`: The pin number
- `value`: `HIGH` (5V, LED on 💡) or `LOW` (0V, LED off ⚫)

### What Do HIGH and LOW Mean?

| Value | What It Does | Voltage | LED |
|-------|-------------|---------|-----|
| `HIGH` | Sends current | 5V | On 💡 |
| `LOW` | No current | 0V | Off ⚫ |

### Example

```cpp
digitalWrite(13, HIGH);  // Turn LED on! 💡
digitalWrite(13, LOW);   // Turn LED off! ⚫
```

<InfoBox type="tip">
  **For kids:** Think of `HIGH` as a light switch turned ON, and `LOW` as the switch turned OFF. You control the light! 💡
</InfoBox>

### How to Make Pauses - Wait a Bit!

The `delay()` function makes Arduino wait before continuing:

```cpp
delay(milliseconds);
```

- 1000 milliseconds = 1 second (you can count "one elephant" 🐘)
- 500 milliseconds = 0.5 seconds (half a second)
- 100 milliseconds = 0.1 seconds (very fast!)

<InfoBox type="info">
  **For kids:** A millisecond is VERY fast - 1000 times faster than a second! Imagine dividing one second into 1000 tiny pieces. ⏱️
</InfoBox>

### Complete Blink Code

Here's the entire program - just 8 lines of magic code! ✨

```cpp
void setup() {
  pinMode(13, OUTPUT);    // Prepare pin 13 to send signals
}

void loop() {
  digitalWrite(13, HIGH); // Turn LED on 💡
  delay(1000);            // Wait 1 second
  digitalWrite(13, LOW);  // Turn LED off ⚫
  delay(1000);            // Wait 1 second
  // Then everything repeats! ♻️
}
```

<InfoBox type="warning">
  **Important:** Don't forget `delay()` between `HIGH` and `LOW`! Without pauses, the LED will turn on and off so fast that your eyes won't see any change - it will look like it's always on!
</InfoBox>

</LessonChapter>

### What's an LED? 

An **LED** is a tiny light - like a mini flashlight!

- 💡 **LED** = **L**ight **E**mitting **D**iode
- It's the same kind of light in your TV remote, toys, and Christmas lights!

  **For parents:** The built-in LED on pin 13 means no external wiring is needed for this first lesson. Your child can focus purely on the code!

<LessonChapter title="Let's Write the Code! ✏️" id="write-the-code">

### Step 1: Tell Arduino "This pin sends signals"

In the **setup()** box, we write:

```cpp
pinMode(13, OUTPUT);
```

This tells Arduino: *"Hey! Pin 13 will **send** signals to turn the light on!"*

### Step 2: Turn the light ON! 💡

In the **loop()** box, we write:

```cpp
digitalWrite(13, HIGH);
```

**HIGH** means ON! The light turns on! ☀️

### Step 3: Wait a little bit... ⏰

```cpp
delay(1000);
```

This makes Arduino **wait** for 1 second. (1000 = 1 second)

### Step 4: Turn the light OFF! ⚫

```cpp
digitalWrite(13, LOW);
```

**LOW** means OFF! The light turns off! 🌙

### Step 5: Wait again... ⏰

```cpp
delay(1000);
```

Wait 1 more second, then it all starts over!

<InfoBox type="warning">
  **Remember:** HIGH = ON (like a light switch UP ⬆️) and LOW = OFF (like a light switch DOWN ⬇️)!
</InfoBox>

<LessonChapter title="The Complete Program! 🎉" id="complete-program">

Here's everything together:

```cpp
void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
```

<LessonChapter title="Fun Experiments! 🧪" id="experiments">

### Make it blink FASTER! 🏃‍♂️

Change `1000` to `100`:
```cpp
delay(100);
```
Now it blinks super fast like a firefly!

### Make it blink SLOWER! 🐢

Change `1000` to `3000`:
```cpp
delay(3000);
```
Now it blinks slowly like a lighthouse!

### Make a pattern! ✨

Try this heartbeat pattern:
```cpp
digitalWrite(13, HIGH);
delay(100);
digitalWrite(13, LOW);
delay(100);
digitalWrite(13, HIGH);
delay(100);
digitalWrite(13, LOW);
delay(500);
```

<InfoBox type="tip">
  **Challenge:** Can you make the LED blink to spell SOS in Morse code? (3 short, 3 long, 3 short!)
</InfoBox>

- ✅ **loop()** runs FOREVER - for the main action  
- ✅ **HIGH** = ON, **LOW** = OFF
- ✅ **delay(1000)** = wait 1 second
- ✅ You can change the number to blink faster or slower!

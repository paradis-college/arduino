```cpp

  // Runs once when Arduino powers on
  // Put initialization code here
}

void loop() {
  // Runs repeatedly forever
  // Put your main code here
}
```

### Configuring Pins

Before using a pin, tell Arduino whether it's an input or output:

```cpp
pinMode(pin, mode);
```

- `pin`: The pin number (0-13 for digital)
- `mode`: `INPUT`, `OUTPUT`, or `INPUT_PULLUP`

### Example

```cpp
void setup() {
  pinMode(13, OUTPUT);  // Pin 13 will send signals out
}
```

</LessonChapter>

<LessonChapter title="digitalWrite() Function" id="digitalwrite-function">

### Setting Pin State

```cpp
digitalWrite(pin, value);
```

- `pin`: The pin number
- `value`: `HIGH` (5V, LED on) or `LOW` (0V, LED off)

### Example

```cpp
digitalWrite(13, HIGH);  // Turn LED on
digitalWrite(13, LOW);   // Turn LED off
```

<LessonChapter title="delay() Function" id="delay-function">

### Pausing Execution

```cpp
delay(milliseconds);
```

- 1000 milliseconds = 1 second
- 500 milliseconds = 0.5 seconds
- 100 milliseconds = 0.1 seconds

### Complete Blink Code

```cpp
void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);  // LED on
  delay(1000);             // Wait 1 second
  digitalWrite(13, LOW);   // LED off
  delay(1000);             // Wait 1 second
}
```

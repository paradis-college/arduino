<LessonChapter title="MQ Sensor Types" id="mq-sensor-types">

### Common MQ Sensors

| Sensor | Detects |
|--------|---------|
| MQ-2 | Smoke, LPG, propane, methane |
| MQ-3 | Alcohol, ethanol |
| MQ-4 | Methane, natural gas |
| MQ-5 | LPG, natural gas |
| MQ-6 | LPG, butane |
| MQ-7 | Carbon monoxide |
| MQ-135 | Air quality (NH3, NOx, benzene) |

### Module Pins

Most MQ modules have 4 pins:
- **VCC**: 5V
- **GND**: Ground
- **DO**: Digital output (threshold trigger)
- **AO**: Analog output (continuous reading)

<LessonChapter title="Warm-Up Period" id="warm-up">

### Why Warm-Up Is Critical

MQ sensors have a heating element that must reach operating temperature:
- **First use**: 24-48 hours for "burn-in"
- **Each power-on**: 2-5 minutes warm-up
- Readings are unreliable until stabilized

```cpp
void setup() {
  Serial.begin(9600);
  Serial.println("Warming up sensor...");
  delay(180000);  // 3 minutes
  Serial.println("Sensor ready!");
}
```

<InfoBox type="warning">
  Don't trust readings during the warm-up period! The sensor needs time to reach stable operating temperature.
</InfoBox>

<LessonChapter title="Reading Gas Levels" id="reading-gas-levels">

### Analog Output

```cpp
const int MQ_PIN = A0;

void loop() {
  int gasValue = analogRead(MQ_PIN);

  Serial.print("Gas level: ");
  Serial.println(gasValue);

  delay(1000);
}
```

### Air Quality Zones

```cpp
void checkAirQuality(int value) {
  if (value < 200) {
    Serial.println("🟢 Good air quality");
  } else if (value < 400) {
    Serial.println("🟡 Moderate - ventilate");
  } else {
    Serial.println("🔴 Poor - danger!");
    // Trigger alarm
  }
}
```

### Calibration

For accurate PPM readings, you need:
1. Clean air baseline (Ro value)
2. Sensor characteristic curves from datasheet
3. Mathematical conversion

For simple projects, relative readings (low/medium/high) work well.

<LessonChapter title="Buzzer Types" id="buzzer-types">

### Active Buzzer

- Has internal oscillator
- Just apply power → makes sound
- One fixed tone/frequency
- Use with `digitalWrite()`

### Passive Buzzer

- No internal oscillator
- Requires PWM signal to generate sound
- Can play different frequencies
- Use with `tone()` function

<InfoBox type="tip">
  For musical projects, use a passive buzzer - it can play any frequency you want!
</InfoBox>

<LessonChapter title="tone() Function" id="tone-function">

### Syntax

```cpp
tone(pin, frequency);           // Play indefinitely
tone(pin, frequency, duration); // Play for duration ms
noTone(pin);                    // Stop the tone
```

- `pin`: The buzzer pin
- `frequency`: Hz (262 = middle C)
- `duration`: Milliseconds (optional)

### Simple Beep

```cpp
const int BUZZER_PIN = 8;

void setup() {
  // No pinMode needed for tone()
}

void loop() {
  tone(BUZZER_PIN, 1000, 500);  // 1kHz for 500ms
  delay(1000);
}
```

<LessonChapter title="Musical Notes" id="musical-notes">

### Note Frequencies (Hz)

```cpp
#define NOTE_C4  262
#define NOTE_D4  294
#define NOTE_E4  330
#define NOTE_F4  349
#define NOTE_G4  392
#define NOTE_A4  440
#define NOTE_B4  494
#define NOTE_C5  523
```

### Playing a Scale

```cpp
int melody[] = {NOTE_C4, NOTE_D4, NOTE_E4, NOTE_F4, 
                NOTE_G4, NOTE_A4, NOTE_B4, NOTE_C5};
int noteDuration = 250;

void playScale() {
  for (int i = 0; i < 8; i++) {
    tone(BUZZER_PIN, melody[i], noteDuration);
    delay(noteDuration + 50);  // Gap between notes
  }
  noTone(BUZZER_PIN);
}
```

### Simple Melody

```cpp
// Twinkle Twinkle Little Star
int melody[] = {NOTE_C4, NOTE_C4, NOTE_G4, NOTE_G4, 
                NOTE_A4, NOTE_A4, NOTE_G4};
int durations[] = {250, 250, 250, 250, 250, 250, 500};

void playMelody() {
  for (int i = 0; i < 7; i++) {
    tone(BUZZER_PIN, melody[i], durations[i]);
    delay(durations[i] + 50);
  }
  noTone(BUZZER_PIN);
}
```

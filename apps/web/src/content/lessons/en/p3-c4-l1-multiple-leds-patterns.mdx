<LessonChapter title="LED Array Setup" id="led-array-setup">

### 8-LED Configuration

```cpp
const int LED_COUNT = 8;
const int ledPins[LED_COUNT] = {2, 3, 4, 5, 6, 7, 8, 9};

void setup() {
  for (int i = 0; i < LED_COUNT; i++) {
    pinMode(ledPins[i], OUTPUT);
  }
}

void allOff() {
  for (int i = 0; i < LED_COUNT; i++) {
    digitalWrite(ledPins[i], LOW);
  }
}

void allOn() {
  for (int i = 0; i < LED_COUNT; i++) {
    digitalWrite(ledPins[i], HIGH);
  }
}
```

<LessonChapter title="Chase Pattern" id="chase-pattern">

### Knight Rider / Cylon Effect

```cpp
void chasePattern(int delayTime) {
  for (int i = 0; i < LED_COUNT; i++) {
    allOff();
    digitalWrite(ledPins[i], HIGH);
    delay(delayTime);
  }
}
```

### Ping-Pong (Back and Forth)

```cpp
void pingPongPattern(int delayTime) {
  // Forward
  for (int i = 0; i < LED_COUNT; i++) {
    allOff();
    digitalWrite(ledPins[i], HIGH);
    delay(delayTime);
  }
  // Backward
  for (int i = LED_COUNT - 2; i > 0; i--) {
    allOff();
    digitalWrite(ledPins[i], HIGH);
    delay(delayTime);
  }
}
```

<LessonChapter title="Binary Count Pattern" id="binary-count">

### Counting in Binary on LEDs

```cpp
void binaryCountPattern(int delayTime) {
  for (int count = 0; count < 256; count++) {  // 8 bits = 0-255
    for (int bit = 0; bit < LED_COUNT; bit++) {
      if (count & (1 << bit)) {
        digitalWrite(ledPins[bit], HIGH);
      } else {
        digitalWrite(ledPins[bit], LOW);
      }
    }
    delay(delayTime);
  }
}
```

### Understanding Bitwise Operations

- `count & (1 << bit)` checks if bit position is set
- LED 0 = 1's place
- LED 1 = 2's place
- LED 2 = 4's place
- etc.

<InfoBox type="tip">
  Binary counting is a great way to visualize how computers store numbers!
</InfoBox>

</LessonChapter>

<LessonChapter title="Speed Control" id="speed-control">

### Using Potentiometer

```cpp
const int SPEED_POT = A0;

void loop() {
  int potValue = analogRead(SPEED_POT);
  int delayTime = map(potValue, 0, 1023, 20, 500);

  chasePattern(delayTime);
}
```

### Pattern Selector

```cpp
int currentPattern = 0;

void loop() {
  int speed = map(analogRead(SPEED_POT), 0, 1023, 20, 300);

  switch (currentPattern) {
    case 0: chasePattern(speed); break;
    case 1: pingPongPattern(speed); break;
    case 2: binaryCountPattern(speed); break;
  }
}
```

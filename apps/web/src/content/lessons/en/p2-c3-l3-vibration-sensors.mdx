# Vibration Sensors

In this lesson, you'll learn how vibration sensors detect movement and shocks, and how to use them for alarm and monitoring systems.

<LessonChapter title="Vibration Sensor Types" id="sensor-types">

### Common Types

**SW-420 Vibration Sensor Module**
- Spring-based tilt/vibration detection
- Digital output (HIGH on vibration)
- Adjustable sensitivity potentiometer
- Very affordable

**Piezo Vibration Sensor**
- Generates voltage when deformed
- Analog output proportional to vibration
- More sensitive to small vibrations
- Better for continuous monitoring

### SW-420 Pins

| Pin | Function |
|-----|----------|
| VCC | 3.3-5V |
| GND | Ground |
| DO | Digital Output |

<LessonChapter title="Reading Vibration" id="reading-vibration">

### Digital Vibration Detection

```cpp
const int VIBRATION_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(VIBRATION_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int vibration = digitalRead(VIBRATION_PIN);
  
  if (vibration == HIGH) {
    digitalWrite(LED_PIN, HIGH);
    Serial.println("Vibration detected!");
    delay(100);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}
```

### Counting Pulses

For tap detection vs continuous vibration:

```cpp
int pulseCount = 0;
unsigned long lastPulse = 0;

void loop() {
  if (digitalRead(VIBRATION_PIN) == HIGH) {
    if (millis() - lastPulse > 50) {  // Debounce
      pulseCount++;
      lastPulse = millis();
    }
  }
  
  // Reset count after 1 second of no vibration
  if (millis() - lastPulse > 1000) {
    if (pulseCount > 0) {
      Serial.print("Pulses: ");
      Serial.println(pulseCount);
      pulseCount = 0;
    }
  }
}
```

<LessonChapter title="Alarm Applications" id="alarm-applications">

### Vibration Alarm

```cpp
const int BUZZER_PIN = 8;
bool armed = true;

void checkVibration() {
  if (armed && digitalRead(VIBRATION_PIN) == HIGH) {
    triggerAlarm();
  }
}

void triggerAlarm() {
  Serial.println("🚨 ALARM TRIGGERED!");
  for (int i = 0; i < 5; i++) {
    digitalWrite(BUZZER_PIN, HIGH);
    delay(200);
    digitalWrite(BUZZER_PIN, LOW);
    delay(200);
  }
}
```

### Use Cases

- **Anti-theft alarm**: Attach to bike, bag, or valuables
- **Earthquake detection**: Monitor ground vibration
- **Machine monitoring**: Detect unusual vibrations
- **Door/window alarm**: Detect forced entry attempts

<InfoBox type="tip">
  Adjust the sensitivity potentiometer to avoid false triggers from normal movement while still detecting significant vibrations.
</InfoBox>

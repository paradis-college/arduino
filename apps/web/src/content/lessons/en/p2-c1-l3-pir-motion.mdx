### How PIR Works

1. Sensor has two infrared-sensitive elements
2. When warm body moves across the field of view
3. One element sees more IR, then the other
4. This difference triggers the output signal

### Pin Configuration

| Pin | Function |
|-----|----------|
| VCC | 5V-12V Power |
| GND | Ground |
| OUT | Digital Output (HIGH when motion detected) |

### Field of View

Typical PIR sensors have:
- ~110° horizontal detection angle
- ~70° vertical detection angle
- 3-7 meter range

### Simple Code

```cpp
const int PIR_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(PIR_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);

  // Allow PIR to stabilize (30-60 seconds)
  delay(30000);
}

void loop() {
  int motion = digitalRead(PIR_PIN);

  if (motion == HIGH) {
    Serial.println("Motion detected!");
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
  delay(100);
}
```

<InfoBox type="warning">
  PIR sensors need 30-60 seconds to stabilize after power-on. Don't move during this calibration period!
</InfoBox>

<LessonChapter title="Adjustments" id="adjustments">

### Onboard Potentiometers

Most PIR modules have two adjustable potentiometers:

1. **Sensitivity**: Adjust detection range
2. **Time Delay**: How long output stays HIGH after detection

### Jumper Settings

Some modules have a jumper to select:
- **H (Repeatable)**: Re-triggers while motion continues
- **L (Non-repeatable)**: Single trigger per motion event

<InfoBox type="tip">
  For security alarms, use non-repeatable mode. For automatic lights, use repeatable mode with longer delay.
</InfoBox>

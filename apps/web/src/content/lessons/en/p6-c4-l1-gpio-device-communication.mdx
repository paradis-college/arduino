<LessonChapter title="Communication Protocols" id="protocols">

### UART (Serial)

- Simple two-wire communication (TX, RX)
- Point-to-point (one device)
- Easy to implement
- Use for: Arduino, GPS, Bluetooth modules

### I2C

- Two wires (SDA, SCL) for many devices
- Addressable devices (up to 127)
- Moderate speed
- Use for: Sensors, displays, RTCs

### SPI

- Four wires (MOSI, MISO, SCK, CS)
- Fast data transfer
- One CS pin per device
- Use for: SD cards, displays, ADCs

<LessonChapter title="UART: Pi to Arduino" id="uart-pi-arduino">

### Wiring

```
Pi GPIO14 (TX) → Arduino RX (via voltage divider!)
Pi GPIO15 (RX) → Arduino TX
Pi GND → Arduino GND
```

<InfoBox type="warning">
  Arduino TX is 5V, Pi RX is 3.3V! Use a voltage divider or level shifter to protect the Pi.
</InfoBox>

### Pi Code (Python)

```python
import serial
from time import sleep

ser = serial.Serial('/dev/ttyS0', 9600, timeout=1)

while True:
    ser.write(b'Hello Arduino\n')
    sleep(1)
    
    if ser.in_waiting > 0:
        response = ser.readline().decode('utf-8').strip()
        print(f"Arduino says: {response}")
```

### Arduino Code

```cpp
void setup() {
  Serial.begin(9600);
}

void loop() {
  if (Serial.available()) {
    String msg = Serial.readStringUntil('\n');
    Serial.print("Received: ");
    Serial.println(msg);
  }
}
```

<LessonChapter title="I2C Communication" id="i2c-communication">

### Enable I2C on Pi

```bash
sudo raspi-config
# Interface Options → I2C → Enable
```

### Scan for Devices

```bash
sudo i2cdetect -y 1
```

### Python I2C Example

```python
import smbus2

bus = smbus2.SMBus(1)  # I2C bus 1
DEVICE_ADDR = 0x48     # Example device address

# Read one byte
data = bus.read_byte_data(DEVICE_ADDR, 0x00)
print(f"Read: {data}")

# Write one byte
bus.write_byte_data(DEVICE_ADDR, 0x01, 0xFF)
```

### Wiring

```
Pi SDA (GPIO2) → Device SDA
Pi SCL (GPIO3) → Device SCL
Pi 3.3V → Device VCC (if 3.3V compatible)
Pi GND → Device GND
```

</LessonChapter>

<LessonChapter title="Protocol Selection" id="protocol-selection">

### When to Use Each

| Need | Protocol | Why |
|------|----------|-----|
| Talk to Arduino | UART | Simple, bidirectional |
| Multiple sensors | I2C | One bus, many devices |
| Fast data (display) | SPI | Highest speed |
| Long distance | UART | More noise tolerant |

<InfoBox type="tip">
  I2C is great for sensors because you can connect many devices with just 2 wires. Check device datasheets for addresses!
</InfoBox>

</LessonChapter>

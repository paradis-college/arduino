<LessonChapter title="DHT Sensor Basics" id="dht-basics">

### DHT11 vs DHT22

| Feature | DHT11 | DHT22 |
|---------|-------|-------|
| Temperature Range | 0-50°C | -40 to 80°C |
| Humidity Range | 20-80% | 0-100% |
| Accuracy | ±2°C, ±5% RH | ±0.5°C, ±2% RH |
| Speed | 1 reading/sec | 0.5 reading/sec |
| Cost | Lower | Higher |

### Wiring

Most DHT modules have 3 pins:
- **VCC**: 3.3V or 5V
- **GND**: Ground
- **DATA**: Digital pin (with 10kΩ pull-up)

<InfoBox type="tip">
  DHT22 is more accurate and has a wider range. Use DHT11 for simple projects where precision isn't critical.
</InfoBox>

<LessonChapter title="Reading Values" id="reading-values">

### Using the DHT Library

```cpp
#include <DHT.h>

#define DHT_PIN 2
#define DHT_TYPE DHT22

DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float humidity = dht.readHumidity();
  float tempC = dht.readTemperature();
  float tempF = dht.readTemperature(true);
  
  if (isnan(humidity) || isnan(tempC)) {
    Serial.println("Failed to read from DHT!");
    return;
  }
  
  Serial.print("Humidity: ");
  Serial.print(humidity);
  Serial.print("%  Temperature: ");
  Serial.print(tempC);
  Serial.println("°C");
  
  delay(2000);  // DHT22 needs 2 seconds between readings
}
```

<LessonChapter title="Comfort Ranges" id="comfort-ranges">

### Temperature Comfort

- **Cold**: Below 18°C (64°F)
- **Comfortable**: 18-24°C (64-75°F)
- **Warm**: 24-28°C (75-82°F)
- **Hot**: Above 28°C (82°F)

### Humidity Comfort

- **Dry**: Below 30% RH
- **Comfortable**: 30-60% RH
- **Humid**: Above 60% RH

### Example Logic

```cpp
String getComfort(float temp, float hum) {
  if (temp < 18) return "Cold";
  if (temp > 28) return "Hot";
  if (hum < 30) return "Dry";
  if (hum > 60) return "Humid";
  return "Comfortable";
}
```

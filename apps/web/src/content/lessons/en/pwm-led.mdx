# PWM LED Control

In this lesson, you'll learn how to control LED brightness using PWM (Pulse Width Modulation).

## What You'll Learn

- What PWM is and how it works
- How to use the `analogWrite()` function
- How to create fade effects

<InfoBox type="info">
  PWM (Pulse Width Modulation) is a technique that allows analog control through digital signals by varying the duration of HIGH pulses in a cycle.
</InfoBox>

## How PWM Works

PWM works by rapidly turning the LED on and off. By varying the ratio between ON and OFF time (duty cycle), our eyes perceive different brightness levels.

- **0** = LED completely off (0% duty cycle)
- **127** = 50% brightness
- **255** = LED fully on (100% duty cycle)

## Required Components

- 1x Arduino Uno
- 1x LED
- 1x 220Ω Resistor
- Jumper wires
- Breadboard

<InfoBox type="warning">
  PWM only works on certain Arduino pins! On Arduino Uno, PWM pins are: 3, 5, 6, 9, 10, 11 (marked with ~).
</InfoBox>

## Fade Code

```cpp
const int LED_PIN = 9;  // PWM pin

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // Fade in (from off to on)
  for (int brightness = 0; brightness <= 255; brightness += 5) {
    analogWrite(LED_PIN, brightness);
    delay(30);
  }
  
  // Fade out (from on to off)
  for (int brightness = 255; brightness >= 0; brightness -= 5) {
    analogWrite(LED_PIN, brightness);
    delay(30);
  }
}
```

## Code Explanation

### `analogWrite(pin, value)`

This function writes a PWM value to a pin.

- `pin` - the PWM pin number (3, 5, 6, 9, 10, or 11)
- `value` - value between 0 (off) and 255 (fully on)

<Checkpoint id="checkpoint-2" lessonKey="en/pwm-led" label="I understand the analogWrite() function" />

### The for loop

The `for` loop allows us to gradually increment or decrement brightness:

```cpp
for (int brightness = 0; brightness <= 255; brightness += 5) {
  // Executes for brightness: 0, 5, 10, 15, ... 255
}
```

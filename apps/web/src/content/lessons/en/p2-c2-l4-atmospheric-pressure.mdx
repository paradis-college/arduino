<LessonChapter title="Sensor Options" id="sensor-options">

### Common Sensors

| Sensor | Measures | Interface |
|--------|----------|-----------|
| BMP180 | Pressure, Temperature | I2C |
| BMP280 | Pressure, Temperature | I2C/SPI |
| BME280 | Pressure, Temperature, Humidity | I2C/SPI |
| BME680 | Pressure, Temp, Humidity, Gas | I2C/SPI |

### I2C Wiring

```
Sensor VCC → Arduino 3.3V or 5V
Sensor GND → Arduino GND
Sensor SDA → Arduino A4
Sensor SCL → Arduino A5
```

<InfoBox type="tip">
  BME280 is a great all-in-one choice - it measures pressure, temperature, AND humidity in one sensor!
</InfoBox>

<LessonChapter title="Reading Pressure" id="reading-pressure">

### Using Adafruit BME280 Library

```cpp
#include <Wire.h>
#include <Adafruit_BME280.h>

Adafruit_BME280 bme;

void setup() {
  Serial.begin(9600);

  if (!bme.begin(0x76)) {
    Serial.println("BME280 not found!");
    while (1);
  }
}

void loop() {
  float pressure = bme.readPressure() / 100.0F;  // hPa
  float temp = bme.readTemperature();
  float humidity = bme.readHumidity();

  Serial.print("Pressure: ");
  Serial.print(pressure);
  Serial.println(" hPa");

  delay(2000);
}
```

### Pressure Units

- **Pascal (Pa)**: SI unit
- **Hectopascal (hPa)**: 1 hPa = 100 Pa
- **Millibar (mbar)**: 1 mbar = 1 hPa
- **mmHg**: 1 hPa ≈ 0.75 mmHg

Standard sea level pressure: **1013.25 hPa**

<LessonChapter title="Weather Correlation" id="weather-correlation">

### Pressure and Weather

| Pressure | Trend | Likely Weather |
|----------|-------|----------------|
| High (above 1020 hPa) | Stable | Clear, sunny |
| Normal (1010-1020) | - | Variable |
| Low (below 1010 hPa) | Falling | Rain, storms |

### Tracking Trends

```cpp
float pressureHistory[6];  // Last 6 readings
int historyIndex = 0;

void updateHistory(float pressure) {
  pressureHistory[historyIndex] = pressure;
  historyIndex = (historyIndex + 1) % 6;
}

String getTrend() {
  float oldest = pressureHistory[(historyIndex + 1) % 6];
  float newest = pressureHistory[historyIndex];
  float diff = newest - oldest;

  if (diff > 2) return "Rising ↑";
  if (diff < -2) return "Falling ↓";
  return "Stable →";
}
```

<InfoBox type="tip">
  Track pressure changes over hours, not minutes. A drop of 3-6 hPa over 3 hours often means a storm is coming!
</InfoBox>

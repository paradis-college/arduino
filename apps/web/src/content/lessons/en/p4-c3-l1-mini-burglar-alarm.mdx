<LessonChapter title="System States" id="system-states">

### State Definitions

| State | Description | LED | Behavior |
|-------|-------------|-----|----------|
| IDLE | System off | Green | No detection |
| ARMED | Monitoring | Yellow | Detecting motion |
| TRIGGERED | Alarm active | Red | Buzzer sounding |

### State Transitions

- IDLE → ARMED: Press button
- ARMED → TRIGGERED: Motion detected
- TRIGGERED → IDLE: Press button (or timeout)
- ARMED → IDLE: Press button (before motion)

<LessonChapter title="Code Structure" id="code-structure">

### Pin and State Definitions

```cpp
const int PIR_PIN = 2;
const int BUTTON_PIN = 3;
const int BUZZER_PIN = 8;
const int LED_GREEN = 9;
const int LED_YELLOW = 10;
const int LED_RED = 11;

enum AlarmState { IDLE, ARMED, TRIGGERED };
AlarmState currentState = IDLE;
```

### State Machine

```cpp
void loop() {
  bool buttonPressed = checkButton();
  bool motionDetected = digitalRead(PIR_PIN) == HIGH;
  
  switch (currentState) {
    case IDLE:
      setLeds(true, false, false);  // Green only
      noTone(BUZZER_PIN);
      if (buttonPressed) {
        currentState = ARMED;
        delay(5000);  // Delay before arming
      }
      break;
      
    case ARMED:
      setLeds(false, true, false);  // Yellow only
      if (buttonPressed) {
        currentState = IDLE;
      } else if (motionDetected) {
        currentState = TRIGGERED;
      }
      break;
      
    case TRIGGERED:
      setLeds(false, false, true);  // Red only
      soundAlarm();
      if (buttonPressed) {
        currentState = IDLE;
        noTone(BUZZER_PIN);
      }
      break;
  }
}
```

### Alarm Sound

```cpp
void soundAlarm() {
  // Alternating tones for siren effect
  tone(BUZZER_PIN, 1000, 200);
  delay(250);
  tone(BUZZER_PIN, 1500, 200);
  delay(250);
}
```

# Transistors as Switches

In this lesson, you'll learn how transistors work as electronic switches, allowing small currents to control larger loads.

<LessonChapter title="What You'll Learn" id="what-youll-learn">

- How base current controls collector-emitter current

### Pin Identification

An NPN transistor has three pins:
- **Base (B)** - Control input, small current here controls the transistor
- **Collector (C)** - Where current flows in from the load
- **Emitter (E)** - Where current flows out to ground

### How It Works

When a small current flows into the base:
1. The transistor "turns on"
2. A much larger current can flow from collector to emitter
3. The gain (hFE) determines the amplification factor (typically 100-300x)

### Arduino to Motor Example

Arduino pins can only provide ~20mA, but motors need much more current. A transistor bridges this gap:

```
Arduino Pin → Base Resistor → Base
Motor+ → Collector
Emitter → Ground
Motor- → Collector (through flyback diode)
```

<InfoBox type="warning">
  Always use a base resistor (typically 1kΩ) to limit current from the Arduino pin. Never connect the base directly to 5V!
</InfoBox>

</LessonChapter>

<LessonChapter title="Switching High-Power Loads" id="high-power-loads">

### LED Strips and Motors

For LED strips or motors that draw more than 40mA:
1. Connect the load between power supply positive and the collector
2. Connect emitter to ground
3. Control via base with a small Arduino signal

### Base Resistor Calculation

```
R_base = (V_arduino - V_be) / I_base
R_base = (5V - 0.7V) / 0.001A = 4.3kΩ (use 1kΩ-4.7kΩ)
```

# Soil Moisture Sensors

In this lesson, you'll learn how to use soil moisture sensors for plant monitoring and automated watering systems.

<LessonChapter title="What You'll Learn" id="what-youll-learn">

- Soil moisture sensor wiring and operation
- Mapping moisture readings to ranges
- Setting water-needed thresholds
- Building plant monitoring projects

<InfoBox type="info">
  Soil moisture sensors measure the water content in soil by detecting electrical conductivity or capacitance changes.
</InfoBox>

</LessonChapter>

<LessonChapter title="Sensor Types" id="sensor-types">

### Resistive Sensors

- Two metal probes measure conductivity
- Wet soil = lower resistance = higher reading
- Cheap but corrode over time
- Good for learning projects

### Capacitive Sensors

- No exposed metal parts
- Measure soil dielectric properties
- Don't corrode, last longer
- Slightly more expensive

<InfoBox type="tip">
  For long-term projects, invest in capacitive sensors. For quick experiments, resistive sensors work fine.
</InfoBox>

<LessonChapter title="Reading and Mapping Values" id="reading-mapping">

### Basic Reading

```cpp
const int MOISTURE_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int rawValue = analogRead(MOISTURE_PIN);
  Serial.print("Raw value: ");
  Serial.println(rawValue);
  delay(1000);
}
```

### Calibration

Test your sensor to find the range:
1. **Dry air**: Note the value (e.g., 1023)
2. **In water**: Note the value (e.g., 300)
3. Map these to 0-100% moisture

```cpp
int moisturePercent = map(rawValue, 1023, 300, 0, 100);
moisturePercent = constrain(moisturePercent, 0, 100);
```

<LessonChapter title="Threshold-Based Control" id="threshold-control">

### Setting Thresholds

```cpp
const int DRY_THRESHOLD = 30;     // Below 30% = needs water
const int WET_THRESHOLD = 70;     // Above 70% = too wet

void checkPlant(int moisture) {
  if (moisture < DRY_THRESHOLD) {
    Serial.println("Plant needs water! 🥀");
    // Could trigger a pump here
  } else if (moisture > WET_THRESHOLD) {
    Serial.println("Soil is very wet 💧");
  } else {
    Serial.println("Moisture is good! 🌱");
  }
}
```

### Automated Watering

```cpp
const int PUMP_PIN = 8;

void waterPlant() {
  digitalWrite(PUMP_PIN, HIGH);
  delay(2000);  // Water for 2 seconds
  digitalWrite(PUMP_PIN, LOW);
}
```

<InfoBox type="warning">
  Don't over-water! Add delays between watering cycles and check that moisture actually increased before stopping.
</InfoBox>

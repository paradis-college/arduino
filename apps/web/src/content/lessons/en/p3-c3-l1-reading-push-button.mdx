<LessonChapter title="Button Wiring" id="button-wiring">

### The Floating Pin Problem

When a button is not pressed and the pin isn't connected to anything, it "floats" - reading random HIGH or LOW values.

### Solution: Pull-Up or Pull-Down Resistor

**Pull-Up (connects to 5V when open)**:
- Pin is HIGH when button not pressed
- Pin is LOW when button pressed
- Arduino has internal pull-ups!

**Pull-Down (connects to GND when open)**:
- Pin is LOW when button not pressed
- Pin is HIGH when button pressed
- Requires external resistor

<LessonChapter title="INPUT_PULLUP Mode" id="input-pullup">

### The Easy Way

Arduino has built-in pull-up resistors! Just use:

```cpp
pinMode(pin, INPUT_PULLUP);
```

Now:
- Button not pressed → reads HIGH
- Button pressed → reads LOW (connects to GND)

### Wiring with INPUT_PULLUP

```
Button terminal 1 → Arduino pin (e.g., pin 2)
Button terminal 2 → GND
```

No external resistor needed!

<InfoBox type="warning">
  With INPUT_PULLUP, the logic is inverted: LOW means pressed, HIGH means not pressed!
</InfoBox>

</LessonChapter>

<LessonChapter title="digitalRead() Function" id="digitalread-function">

### Reading Button State

```cpp
int buttonState = digitalRead(pin);
```

Returns `HIGH` or `LOW`.

### Complete Example

```cpp
const int BUTTON_PIN = 2;
const int LED_PIN = 13;

void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == LOW) {  // LOW = pressed with INPUT_PULLUP
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}
```
